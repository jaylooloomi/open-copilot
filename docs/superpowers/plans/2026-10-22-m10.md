**Goal:** 依追加設計 §5，錄音時在 ActionBar 顯示 `mm:ss` 計時器、由 `SegmentRecorder` 新增的 `onLevel(rms)` 回呼驅動的 5 格音量條（約每 100ms 更新、`aria-hidden`），以及「轉寫中 N 段」（N = 已上傳但還沒插入的段數，N = 0 不顯示）；超過 10 秒沒有任何讀數高於門檻時顯示一次「沒有偵測到聲音，請確認麥克風」，收到聲音後自動消失；停止錄音後計時器和音量條都消失。

**Architecture:** 三個純模組放在 `packages/core/src/recording/`：`recordingDisplay.ts`（`formatElapsed`、`levelToBars`）、`noSoundDetector.ts`（10 秒無聲判斷）、`levelStore.ts`（音量的外部 store 與 `useLevel`，讓每 100ms 的音量只重繪音量條，不重繪整個 `NotesApp`）。`SegmentRecorder` 在原本 50ms 的輪詢裡，把真實讀數節流成約每 100ms 呼叫一次 `onLevel`。`useRecorder` 多回傳 `startedAt`、`levels`、`noSound`、`transcribing`。新元件 `components/RecordingStatus.tsx` 顯示計時器、音量條與「轉寫中 N 段」，由 `ActionBar` 放在「錄製」鈕旁邊；無聲提示由 `NotesApp` 顯示在 Banner 下方。

**Tech Stack:** React 19（`useSyncExternalStore`）、TypeScript 5.9、Web Audio `AnalyserNode`、Vitest 3 + Testing Library + jsdom（假時鐘、假音量）、Playwright 1.64（以 Web Audio 正弦波取代麥克風的網頁 e2e）。

## 設計決定

1. **讀數來源**：`SegmentRecorder` 原本每 50ms 讀一次 analyser 的 RMS 餵給 `SegmentPolicy`。新的 `onLevel` 沿用同一次讀數，以 `levelMs`（預設 100）節流：距上次回報不足 `levelMs` 就略過，因此在 50ms 輪詢下是 50、150、250…ms 各一次。**只回報真實讀數**：沒有 analyser（建立 `AudioContext` 失敗）或 context 不是 `running` 時不呼叫 `onLevel`；原本「沒有讀數就當作有聲音」的切段行為不變（`policy.update(now, level ?? 1)`）。`onLevel` 丟錯只記錄 `console.error('Failed to report the microphone level', error)`，不影響切段。
2. **計時起點**：設計寫「從按下『錄製』開始計時」。按下後若跳出麥克風權限提示，使用者可能停在提示上很久，那段時間沒有錄到任何聲音；因此計時從**錄音真正開始**（`recorder.start()` 成功、狀態變成 `recording` 的那一刻，`deps.now()`）起算。沒有權限提示時兩者相差不到一瞬間。計時器以 `startedAt` 與目前時間相減算出，每 250ms 重算一次，`mm:ss` 取整秒（無條件捨去），分鐘超過 99 照樣顯示（`100:00`）。
3. **音量條**：5 格，`levelToBars(rms)` = RMS 達到 `[0.01, 0.03, 0.06, 0.12, 0.2]` 中幾個門檻。第一個門檻 0.01 與 `SegmentPolicy` 的靜音門檻（預設 `threshold: 0.01`）相同，所以 0 格就代表「靜音」。NaN 算 0 格。容器 `aria-hidden="true"`，並以 `data-level` 標出亮幾格，供測試讀取。
4. **重繪範圍**：音量每 100ms 變一次，若放進 `useRecorder` 的 React state，整個 `NotesApp`（含編輯器與工具列）每秒會重繪 10 次。因此音量放在 `levelStore`（`get`／`set`／`subscribe`），只有音量條元件以 `useSyncExternalStore` 訂閱。`startedAt`、`noSound`、`transcribing` 變動很少，用一般 state。
5. **無聲提示**：`NoSoundDetector` 以錄音開始時間為起點，每筆讀數：RMS **不小於** 0.01（含 NaN，與 `SegmentPolicy` 一致）就把「安靜起點」設為這一刻並隱藏提示；否則若 `now - 安靜起點` **嚴格大於** 10,000ms 且這次錄音還沒顯示過，就顯示。設計寫「顯示一次」：每次錄音最多顯示一次，收到聲音消失後不再出現；下一次錄音重新計算。判斷只靠讀數：沒有 analyser 的環境（例如 jsdom、`AudioContext` 建立失敗）不會有讀數，也就不會顯示，避免無法量測時誤報。`useRecorder` 只在顯示狀態改變時才 `setNoSound`。
6. **「轉寫中 N 段」**：N = `onSegment` 交來的段數 − 已經離開 `OrderedBuffer` 的段數。依序插入，所以第 2 段先轉寫完、還在等第 1 段時仍算在 N 裡；轉寫結果為空白（略過）、變成 ⚠ 未轉寫標記，也都在離開 buffer 時扣掉。停止錄音期間（`stopping`）最後一段仍會計入，所有上傳結束後歸 0。卸載後的遲到結果不再更新 state。
7. **停止後消失**：`finish()` 一開始（狀態變成 `stopping` 的同時）就把 `startedAt` 設回 `null`、`noSound` 設回 `false`、音量設回 0，之後收到的讀數一律忽略；`RecordingStatus` 也只在 `recording` 狀態顯示計時器與音量條。「轉寫中 N 段」在 `stopping` 期間繼續顯示，直到歸 0。
8. **呈現位置與無障礙**：`RecordingStatus` 放在 ActionBar「錄製」鈕之後、AI 按鈕之前，`white-space: nowrap`、`flex-shrink: 0`，計時器用 `font-variant-numeric: tabular-nums`，數字變動時寬度不變。計時器是 `role="timer"`（預設不朗讀）並有 `aria-label="錄音時間"`；「轉寫中 N 段」與無聲提示是 `role="status"`，**只在有內容時才渲染**，因為既有 `export.spec.ts` 以 `page.getByRole('status')` 讀取 `NoteActions` 唯一的狀態列（匯出時不在錄音，不會衝突）。無聲提示的文字很長，放不進手機寬度的 ActionBar，所以由 `NotesApp` 顯示在 Banner 下方（`.oc-no-sound`，與既有錄音提示同色系）。
9. **e2e 的假麥克風**：Chrome 的 `--use-fake-device-for-media-stream` 只有週期性的短嗶聲，無法穩定測「10 秒無聲」或「音量條亮滿」。新的 e2e 以 `page.addInitScript` 把 `navigator.mediaDevices.getUserMedia` 換成 Web Audio 440Hz 正弦波（`OscillatorNode → GainNode → MediaStreamDestination`），測試可隨時用 `__ocSetMicLevel(level)` 調整音量（0 = 完全無聲；0.5 的正弦波 RMS ≈ 0.35，5 格全亮）。`MediaRecorder` 與 app 的 analyser 都照常處理這個串流。

/**
 * RMS a bar needs to light up, quietest first. The first step equals SegmentPolicy's default
 * silence threshold (0.01), so 0 bars means "silence".
 */
export const LEVEL_STEPS: readonly number[] = [0.01, 0.03, 0.06, 0.12, 0.2];

/** Number of bars in the level meter. */
export const LEVEL_BARS = LEVEL_STEPS.length;

/** How many bars a microphone reading lights (0–5); NaN lights none. */
export function levelToBars(rms: number): number {
  return LEVEL_STEPS.filter((step) => rms >= step).length;
}

/** Elapsed recording time as mm:ss, whole seconds rounded down; minutes may exceed 99. */
export function formatElapsed(ms: number): string {
  const totalSeconds = Number.isFinite(ms) && ms > 0 ? Math.floor(ms / 1000) : 0;
  const minutes = Math.floor(totalSeconds / 60);
  const seconds = totalSeconds % 60;
  return `${String(minutes).padStart(2, '0')}:${String(seconds).padStart(2, '0')}`;
}
```

/** A reading below this counts as silence (SegmentPolicy's default threshold). */
export const NO_SOUND_THRESHOLD = 0.01;

/** The hint shows once readings stayed below the threshold for longer than this. */
export const NO_SOUND_AFTER_MS = 10_000;

export interface NoSoundOptions {
  threshold?: number;
  afterMs?: number;
}

/**
 * Decides when to show 沒有偵測到聲音，請確認麥克風: after more than `afterMs` without any reading at
 * or above the threshold, counted from the start of the recording. Shown at most once per
 * recording (one detector per recording); a loud reading hides it.
 */
export class NoSoundDetector {
  private readonly threshold: number;
  private readonly afterMs: number;
  private quietSinceMs: number;
  private shownOnce = false;
  private visible = false;

  constructor(startMs: number, options: NoSoundOptions = {}) {
    this.threshold = options.threshold ?? NO_SOUND_THRESHOLD;
    this.afterMs = options.afterMs ?? NO_SOUND_AFTER_MS;
    this.quietSinceMs = startMs;
  }

  /** Feeds one reading; returns whether the hint should be shown now. */
  update(nowMs: number, rms: number): boolean {
    // `!(rms < threshold)` so that NaN counts as sound, as in SegmentPolicy.
    if (!(rms < this.threshold)) {
      this.quietSinceMs = nowMs;
      this.visible = false;
      return false;
    }
    if (!this.shownOnce && nowMs - this.quietSinceMs > this.afterMs) {
      this.shownOnce = true;
      this.visible = true;
    }
    return this.visible;
  }
}
```

import { useSyncExternalStore } from 'react';

/** Read side of the microphone level, for components. */
export interface LevelSource {
  get(): number;
  /** Returns the unsubscribe function. */
  subscribe(listener: () => void): () => void;
}

export interface LevelStore extends LevelSource {
  set(level: number): void;
}

/**
 * The latest microphone level (RMS). Kept outside React state so that a new reading every ~100ms
 * re-renders only the level meter, not the whole app.
 */
export function createLevelStore(): LevelStore {
  let level = 0;
  const listeners = new Set<() => void>();
  return {
    get: () => level,
    set: (next) => {
      const value = Number.isFinite(next) ? next : 0;
      if (value === level) return;
      level = value;
      for (const listener of [...listeners]) listener();
    },
    subscribe: (listener) => {
      listeners.add(listener);
      return () => {
        listeners.delete(listener);
      };
    },
  };
}

const NO_SOURCE: LevelSource = {
  get: () => 0,
  subscribe: () => () => undefined,
};

/** The current level of `source` (0 without one); re-renders when it changes. */
export function useLevel(source: LevelSource | undefined): number {
  const store = source ?? NO_SOURCE;
  return useSyncExternalStore(store.subscribe, store.get, store.get);
}

export function useRecorder(options: UseRecorderOptions): UseRecorderResult {
  const [phase, setPhase] = useState<Phase>('idle');
  const [error, setError] = useState<string | null>(null);
  const [notice, setNotice] = useState<string | null>(null);
  const [startedAt, setStartedAt] = useState<number | null>(null);
  const [noSound, setNoSound] = useState(false);
  const [levels] = useState(createLevelStore);
  const queue = useMemo(() => createPendingQueue(options.db), [options.db]);

  const latest = useRef({ options, queue });
  useLayoutEffect(() => {
    latest.current = { options, queue };
  });

  const controllerRef = useRef<ReturnType<typeof createRecorderController> | null>(null);
  controllerRef.current ??= createRecorderController({
    options: () => latest.current.options,
    queue: () => latest.current.queue,
    levels,
    setPhase,
    setError,
    setNotice,
    setStartedAt,
    setNoSound,
  });
  const controller = controllerRef.current;

  useEffect(() => {
    // Set here as well as in dispose() so that StrictMode's unmount and remount works.
    controller.mount();
    document.addEventListener('visibilitychange', controller.onVisibilityChange);
    return () => {
      document.removeEventListener('visibilitychange', controller.onVisibilityChange);
      controller.dispose();
    };
  }, [controller]);

  // New settings (e.g. after a rejected key was replaced) clear the old error.
  const { apiBaseUrl, accessKey } = options.settings;
  useEffect(() => {
    setError(null);
  }, [apiBaseUrl, accessKey]);

    phase !== 'idle' ? phase : isConfigured(options.settings) ? 'idle' : 'needsSetup';

    error,
    notice,
    startedAt,
    levels,
    noSound,
    start: controller.start,
    stop: controller.stop,
    retryGap: controller.retryGap,

  async function start(): Promise<void> {
    const { editor, noteId, settings } = env.options();
    if (session || starting || !noteId || !isConfigured(settings)) return;
    starting = true;
    try {
      const d = deps();
      env.setError(null);
      env.setNotice(null);
      let stream: MediaStream;
      try {
        stream = await d.getUserMedia();
      } catch {
        env.setError(RECORDER_MESSAGES.micDenied);
        return;
      }
      // The permission prompt does not block the page, so the user may have opened another note
      // (useNoteEditor then destroys this editor) or changed the settings meanwhile. Only record
      // into the note that is still on screen.
      const now = env.options();
      if (
        !mounted ||
        now.noteId !== noteId ||
        now.editor !== editor ||
        editor.isDestroyed ||
        !isConfigured(now.settings)
      ) {
        stopTracks(stream);
        return;
      }
      const mimeType = d.pickMimeType();
      // The timer counts from here: the microphone is granted and recording begins.
      const startedAt = d.now();
      // Assigned right below, before the recorder can call back.
      let current: Session;
      const recorder = d.createRecorder({
        stream,
        mimeType,
        onSegment: (segment) => handleSegment(current, segment),
        onInterrupted: () => handleInterrupted(current),
        onLevel: (rms) => handleLevel(current, rms),
      });
      current = {
        noteId,
        client: d.createClient(now.settings),
        stream,
        recorder,
        inserter: new TranscriptInserter(editor, editor.state.selection.to),
        buffer: new OrderedBuffer<SegmentResult>(),
        mimeType,
        transcript: '',
        uploads: new Set(),
        unauthorized: false,
        finishing: null,
        disposed: false,
        noSound: new NoSoundDetector(startedAt),
        noSoundShown: false,

      try {
        recorder.start();
      } catch (error) {
        console.error('Failed to start recording', error);
        stopTracks(stream);
        current.inserter.destroy();
        env.setError(RECORDER_MESSAGES.startFailed);
        return;

      env.setPhase('recording');
      env.setStartedAt(startedAt);

      starting = false;

  function finish(current: Session): Promise<void> {
    current.finishing ??= (async () => {
      env.setPhase('stopping');
      clearLiveFeedback();
      // Delivers the last segment through onSegment before it resolves.
      await current.recorder
        .stop()
        .catch((error: unknown) => console.error('Failed to stop recording', error));
      stopTracks(current.stream);
      while (current.uploads.size > 0) await Promise.allSettled([...current.uploads]);
      current.inserter.destroy();
      if (session === current) session = null;
      env.setPhase('idle');
    })();
    return current.finishing;
  }

  function handleLevel(current: Session, rms: number): void {
    // Readings after stop() began, after unmount or from an older recording must not bring the
    // meter or the hint back.
    if (session !== current || current.finishing || current.disposed) return;
    env.levels.set(rms);
    const shown = current.noSound.update(deps().now(), rms);
    if (shown !== current.noSoundShown) {
      current.noSoundShown = shown;
      env.setNoSound(shown);
    }
  }

  /** Timer, level meter and no-sound hint are only shown while recording. */
  function clearLiveFeedback(): void {
    env.setStartedAt(null);
    env.setNoSound(false);
    env.levels.set(0);

  function handleSegment(current: Session, { seq, blob }: RecordedSegment): void {
    current.waiting += 1;
    reportWaiting(current);
    const prompt = tail(current.transcript, PROMPT_CHARS);
    const mimeType = blob.type || current.mimeType || '';
    const upload: Promise<void> = transcribeSegment(current, seq, blob, mimeType, prompt)
      .catch((error: unknown) => {
        console.error(`Failed to handle segment ${seq}`, error);
        // This seq must still reach the buffer, or every later transcript would wait behind it.
        return { kind: 'skip' } as const;

  /** Inserts every result that is now next in line. */
  function release(current: Session, seq: number, result: SegmentResult): void {
    const ready = current.buffer.put(seq, result);
    for (const item of ready) {
      // One failing insert must not drop the rest of the batch, which has already left the buffer.
      try {
        if (item.kind === 'text') {
          current.inserter.insertText(item.text);
          current.transcript += item.text;
        } else if (item.kind === 'gap') {
          // Unmounted while its audio was being stored: no marker, so do not keep the audio.
          if (current.disposed) void dropPending(item.gapId);
          else current.inserter.insertGap(item.gapId, item.seq);
        }
      } catch (error) {
        console.error('Failed to insert a transcript', error);
      }
    }
    if (ready.length > 0) {
      current.waiting -= ready.length;
      reportWaiting(current);
    }
  }

  /** 轉寫中 N 段; an unmounted recording no longer shows anything. */

function RecordingTimer({ startedAt, now }: { startedAt: number; now: () => number }) {
  const [elapsed, setElapsed] = useState(() => now() - startedAt);
  useEffect(() => {
    setElapsed(now() - startedAt);
    // Recomputed from the clock, so a late tick never lets the timer drift.
    const id = setInterval(() => setElapsed(now() - startedAt), 250);
    return () => clearInterval(id);
  }, [startedAt, now]);
  return (
    <span className="oc-rec-timer" role="timer" aria-label="錄音時間">
      {formatElapsed(elapsed)}
    </span>
  );
}

function LevelMeter({ levels }: { levels: LevelSource | undefined }) {
  const bars = levelToBars(useLevel(levels));
  return (
    <span className="oc-level-meter" aria-hidden="true" data-level={bars}>
      {Array.from({ length: LEVEL_BARS }, (_, index) => (
        <span key={index} className={index < bars ? 'oc-level-bar is-on' : 'oc-level-bar'} />
      ))}
    </span>
  );
}

function seqOf(route: Route): number {
  const body = route.request().postDataBuffer()?.toString('latin1') ?? '';
  const match = /name="seq"\r\n\r\n(\d+)/.exec(body);

 * Replaces the microphone with a 440 Hz tone whose loudness the test sets with setMicLevel():
 * 0 is total silence, 0.5 (RMS about 0.35) lights all five bars. Chrome's own fake device only
 * beeps now and then, which can test neither a full meter nor 10 quiet seconds.
 */
async function installToneMicrophone(page: Page, initialLevel: number) {
  await page.addInitScript((initial) => {
    let level = initial;
    let gain: GainNode | null = null;
    Object.assign(window, {
      __ocSetMicLevel: (value: number) => {
        level = value;
        if (gain) gain.gain.value = value;
      },
    });
    navigator.mediaDevices.getUserMedia = async () => {
      const context = new AudioContext();
      const oscillator = context.createOscillator();
      oscillator.frequency.value = 440;
      const node = context.createGain();
      node.gain.value = level;
      gain = node;
      const destination = context.createMediaStreamDestination();
      oscillator.connect(node).connect(destination);
      oscillator.start();
      await context.resume().catch(() => undefined);
      return destination.stream;
    };
  }, initialLevel);
}
