## 設計決定

1. **prompt 截斷套用到兩種服務**：設計說「後端要截斷 prompt」，沒有限定 Groq。兩種服務共用 `buildPrompt` 可以避免規則分岔；prompt 只是提示，OpenAI 少看 120 字影響很小。以 Unicode 字元（`Array.from`）計算，不會切開代理對。
2. **上游 429 兩種服務都處理**：契約變更第 3 點寫的是「上游 429 改為回 429」。OpenAI 的 429（含額度用完）也照此處理，前端依 `withRetry` 的 429 規則等待並計入重試次數。
3. **`Retry-After` 解析**：接受十進位秒數（含小數，無條件進位，最少 1）與 IMF-fixdate 格式的 HTTP 日期（換算成距離現在的秒數，最少 1）；其他值或缺少時用 `10`。上游給的大數值照樣轉傳，不設上限（設計要求「轉傳」）。
4. **用戶端已斷線優先**：`signal.aborted` 時維持原本的 502 與「client disconnected」紀錄，不看錯誤型別。
5. **可注入 `fetch` 只給測試**：`createOpenAIClient`／`createGroqClient`／`createTranscriber` 多一個選填的 `{ fetch }`；`server.ts` 從不傳入，上游位址仍然寫死。
6. **啟動失敗只印一行**：`server.ts` 攔下 `loadConfig` 的錯誤，印 `[config] <訊息>` 後以 exit code 1 結束，不印 stack。訊息不含任何金鑰。啟動成功時印出 provider 與模型。

```ts
export const PROMPT_PREFIX = '以下是繁體中文的語音內容。';

/**
 * Whisper 系列的 prompt 上限是 224 tokens。前端照樣送前一段的最後 200 字，
```

```ts
    async transcribe({ file, prompt, signal }) {
      const result = await openai.audio.transcriptions.create(
```

```ts
import { APIError } from 'openai';

/** 上游 429 沒帶 Retry-After（或看不懂）時，要前端等待的秒數。 */
export const DEFAULT_UPSTREAM_RETRY_AFTER_SECONDS = 10;

const DELAY_SECONDS = /^\d+(?:\.\d+)?$/;
// RFC 9110 的 IMF-fixdate，例如 "Thu, 22 Oct 2026 08:00:15 GMT"。
const IMF_FIXDATE = /^[A-Za-z]{3}, \d{2} [A-Za-z]{3} \d{4} \d{2}:\d{2}:\d{2} GMT$/;

/** 轉寫服務（Groq／OpenAI）回 429：app.ts 改回 429 rate_limited，並帶 Retry-After。 */
export class UpstreamRateLimitError extends Error {
  readonly retryAfterSeconds: number;

  constructor(retryAfterSeconds: number, options?: ErrorOptions) {
    super(`upstream rate limited; retry after ${retryAfterSeconds}s`, options);
    this.name = 'UpstreamRateLimitError';
    this.retryAfterSeconds = retryAfterSeconds;
  }
}

/** 解析上游的 Retry-After（秒數或 HTTP 日期），回傳至少 1 的整數秒；看不懂就回 10。 */
export function parseRetryAfter(value: string | null | undefined, now: number = Date.now()): number {
  const raw = value?.trim() ?? '';
  if (DELAY_SECONDS.test(raw)) {
    return Math.max(1, Math.ceil(Number(raw)));
  }
  if (IMF_FIXDATE.test(raw)) {
    const at = Date.parse(raw);
    if (!Number.isNaN(at)) return Math.max(1, Math.ceil((at - now) / 1000));
  }
  return DEFAULT_UPSTREAM_RETRY_AFTER_SECONDS;
}

/**
 * 把上游 SDK 的錯誤轉成 app.ts 認得的型別：429 → UpstreamRateLimitError，其他原樣回傳。
 * 兩種轉寫服務都走 OpenAI SDK，所以都用 APIError 判斷。
 */
export function toUpstreamError(err: unknown): unknown {
  if (err instanceof APIError && err.status === 429) {
    return new UpstreamRateLimitError(parseRetryAfter(err.headers?.get('retry-after')), {
      cause: err,
    });
  }
  return err;
}
```

```ts
import {
  MAX_AUDIO_BYTES,
  RATE_LIMIT_PER_MINUTE,
  type ApiErrorBody,
  type HealthResponse,
  type TranscribeResponse,
} from '@oc/shared';
import { Hono } from 'hono';
import { bodyLimit } from 'hono/body-limit';
import { cors } from 'hono/cors';
import { bearerAuth, type AuthEnv } from './middleware/auth';
import { rateLimit } from './middleware/rateLimit';
import { toTraditional } from './text/toTraditional';
import { UpstreamRateLimitError } from './transcriber/errors';
import type { Transcriber } from './transcriber/types';

export interface AppDeps {
  transcriber: Transcriber;
  accessKeys: string[];
  allowedOrigins: string[];
  now?: () => number;
}

/** multipart 邊界、seq、prompt 等欄位的額外空間；音訊本身另以 MAX_AUDIO_BYTES 檢查。 */
export const MULTIPART_OVERHEAD_BYTES = 64 * 1024;

const RATE_LIMIT_WINDOW_MS = 60_000;
const SEQ_PATTERN = /^[1-9]\d*$/;

export function createApp({ transcriber, accessKeys, allowedOrigins, now = Date.now }: AppDeps) {
  const app = new Hono<AuthEnv>();

  // CORS 必須最先執行：預檢請求不帶 Authorization，且 401/413/429 回應也要有 CORS 標頭。
  app.use(
    '*',
    cors({
      origin: allowedOrigins,
      allowMethods: ['GET', 'POST', 'OPTIONS'],
      allowHeaders: ['Authorization', 'Content-Type'],
      exposeHeaders: ['Retry-After'],
      maxAge: 600,
    }),
  );

  app.get('/health', (c) => c.json({ ok: true } satisfies HealthResponse));

  app.post(
    '/transcribe',
    bearerAuth(accessKeys),
    rateLimit({ limit: RATE_LIMIT_PER_MINUTE, windowMs: RATE_LIMIT_WINDOW_MS, now }),
    bodyLimit({
      maxSize: MAX_AUDIO_BYTES + MULTIPART_OVERHEAD_BYTES,
      onError: (c) => c.json({ error: 'payload_too_large' } satisfies ApiErrorBody, 413),
    }),
    async (c) => {
      let body: Record<string, string | File>;
      try {
        body = await c.req.parseBody();
      } catch {
        return c.json({ error: 'bad_request' } satisfies ApiErrorBody, 400);
      }

      const audio = body['audio'];
      const rawSeq = body['seq'];
      const prompt = body['prompt'] ?? '';

      if (!(audio instanceof File) || audio.size === 0) {
        return c.json({ error: 'bad_request' } satisfies ApiErrorBody, 400);
      }
      if (audio.size > MAX_AUDIO_BYTES) {
        return c.json({ error: 'payload_too_large' } satisfies ApiErrorBody, 413);
      }
      if (typeof rawSeq !== 'string' || !SEQ_PATTERN.test(rawSeq)) {
        return c.json({ error: 'bad_request' } satisfies ApiErrorBody, 400);
      }
      const seq = Number(rawSeq);
      if (!Number.isSafeInteger(seq) || typeof prompt !== 'string') {
        return c.json({ error: 'bad_request' } satisfies ApiErrorBody, 400);
      }

      // 用戶端斷線（前端逾時、離開頁面）時 node-server 會 abort 這個 signal，上游呼叫跟著取消。
      const signal = c.req.raw.signal;
      let rawText: string;
      try {
        rawText = await transcriber.transcribe({ file: audio, prompt, signal });
      } catch (err) {
        if (signal.aborted) {
          // 回應已經沒人收；記一行說明，避免被誤認成上游故障。
          console.warn('[transcribe] client disconnected; upstream call cancelled');
        } else if (err instanceof UpstreamRateLimitError) {
          // 轉寫服務（例如 Groq 免費額度）限流：改回 429，前端依 Retry-After 等待後重送。
          console.warn(`[transcribe] upstream rate limited; retry after ${err.retryAfterSeconds}s`);
          c.header('Retry-After', String(err.retryAfterSeconds));
          return c.json({ error: 'rate_limited' } satisfies ApiErrorBody, 429);
        } else {
          // 只記錄錯誤訊息，不記錄金鑰或音訊內容。
          console.error('[transcribe] upstream error:', err instanceof Error ? err.message : String(err));
        }
        return c.json({ error: 'upstream_error' } satisfies ApiErrorBody, 502);
      }

      return c.json({ seq, text: toTraditional(rawText.trim()) } satisfies TranscribeResponse, 200);
    },
  );

  // 未知路徑或方法（例如 GET /transcribe、多了路徑前綴的後端網址）也回 JSON，M3b 才能一律解析錯誤 body。
  app.notFound((c) => c.json({ error: 'bad_request' } satisfies ApiErrorBody, 404));

  // 中介層與 handler 沒接住的例外（例如 toTraditional、parseBody 內部錯誤）回 JSON 500；只記錄訊息，不記錄金鑰或音訊。
  app.onError((err, c) => {
    console.error('[api] unhandled error:', err instanceof Error ? err.message : String(err));
    return c.json({ error: 'upstream_error' } satisfies ApiErrorBody, 500);
  });

  return app;
}
```

```ts
import { vi } from 'vitest';

/** 假上游收到的一次請求：網址、Authorization 與 multipart 欄位（檔案記成 file:<檔名>）。 */
export interface UpstreamCall {
  url: string;
  authorization: string | null;
  fields: Record<string, string>;
}

/**
 * 假的上游 fetch，注入真正的 OpenAI SDK client（ClientOptions.fetch）。
 * SDK 照常組 multipart、解析回應與錯誤，只是不連網。
 * `calls` 只記錄真正送到上游的 multipart 請求；要斷言「呼叫上游幾次」請用 `calls.length`，
 * 不要用 `fetch` 的呼叫次數。
 */
export function createFakeUpstream(respond: (call: UpstreamCall) => Response) {
  const calls: UpstreamCall[] = [];
  // OpenAI SDK 第一次看到新的 fetch 函式時，若它沒有 `Response` 屬性，會先用它送一次
  // `fetch('data:,')` 探測 FormData 支援（openai/internal/uploads.js 的 supportsFormData）。
  // 掛上全域 Response 讓 SDK 跳過這次探測，fetch 的呼叫次數才等於真正的上游請求數。
  const fetch = Object.assign(vi.fn(async (input: string | URL | Request, init?: RequestInit) => {
    const request = new Request(input, init);
    const form = await request.formData();
    const fields: Record<string, string> = {};
    for (const [name, value] of form.entries()) {
      fields[name] = typeof value === 'string' ? value : `file:${value.name}`;
    }
    const call: UpstreamCall = {
      url: request.url,
      authorization: request.headers.get('authorization'),
      fields,
    };
    calls.push(call);
    return respond(call);
  }), { Response });
  return { fetch, calls };
}

export function jsonResponse(
  status: number,
  body: unknown,
  headers: Record<string, string> = {},
): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { 'content-type': 'application/json', ...headers },
  });
}

/**
 * 測試不可連網：把全域 fetch 換成會丟錯的假物件。在 beforeEach 呼叫，
 * afterEach 用 vi.unstubAllGlobals() 還原。沒注入假上游的 SDK client 會因此失敗，而不是打到真的 API。
 */
export function blockRealNetwork(): void {
  vi.stubGlobal(
    'fetch',
    vi.fn(async () => {
      throw new Error('tests must not reach the network');
    }),
  );
}
```

```ts
import OpenAI, { type ClientOptions } from 'openai';
import { toUpstreamError } from './errors';
import { buildPrompt } from './prompt';
import type { Transcriber } from './types';

// 實作在 prompt.ts，與 Groq 共用；既有程式與測試從這裡匯入，所以重新匯出。
export { PROMPT_PREFIX, PROMPT_TAIL_CHARS, buildPrompt } from './prompt';

export const TRANSCRIBE_MODEL = 'gpt-4o-mini-transcribe';

/**
 * 單次上游呼叫的逾時（OpenAI 與 Groq 共用）。M3b 的 REQUEST_TIMEOUT_MS 是 30 秒（含上傳），
 * 伺服器的最壞情況必須比它短，前端才不會放棄一個伺服器其實會回應的請求。
 */
export const OPENAI_TIMEOUT_MS = 25_000;

/**
 * SDK 不重試（OpenAI 與 Groq 共用）：重試全部交給前端 withRetry（1s→2s→4s）。SDK 若再重試，
 * 一次前端請求會變成多次計費呼叫，最壞耗時也會超過前端逾時。
 */
export const OPENAI_MAX_RETRIES = 0;

/**
 * 固定的上游位址。SDK 預設會讀主機的 OPENAI_BASE_URL；若主機為別的工具設了它，
 * 使用者的音訊與 OpenAI 金鑰就會被默默送到那裡，所以這裡明確指定。
 */
export const OPENAI_BASE_URL = 'https://api.openai.com/v1';

export interface UpstreamClientOptions {
  /** 只給測試注入假上游；server.ts 從不傳入，一律使用 Node 內建的 fetch。 */
  fetch?: ClientOptions['fetch'];
}

export function createOpenAIClient(apiKey: string, options: UpstreamClientOptions = {}): OpenAI {
  return new OpenAI({
    apiKey,
    baseURL: OPENAI_BASE_URL,
    // 同理不吃主機的 OPENAI_ORG_ID / OPENAI_PROJECT_ID：設定只來自 README 列出的環境變數。
    organization: null,
    project: null,
    timeout: OPENAI_TIMEOUT_MS,
    maxRetries: OPENAI_MAX_RETRIES,
    fetch: options.fetch,
  });
}

export function createOpenAITranscriber(apiKey: string, client?: OpenAI): Transcriber {
  const openai = client ?? createOpenAIClient(apiKey);
  return {
    async transcribe({ file, prompt, signal }) {
      try {
        const result = await openai.audio.transcriptions.create(
          {
            file,
            model: TRANSCRIBE_MODEL,
            language: 'zh',
            prompt: buildPrompt(prompt),
            response_format: 'json',
          },
          // 用戶端斷線時取消上游呼叫，不讓已被放棄的請求繼續計費、和前端重試疊在一起。
          { signal },
        );
        return result.text;
      } catch (err) {
        // 上游 429 轉成 UpstreamRateLimitError，app.ts 才能回 429 並轉傳 Retry-After。
        throw toUpstreamError(err);
      }
    },
  };
}
```

```ts
import OpenAI from 'openai';
import { toUpstreamError } from './errors';
import {
  OPENAI_MAX_RETRIES,
  OPENAI_TIMEOUT_MS,
  type UpstreamClientOptions,
} from './openaiTranscriber';
import { buildPrompt } from './prompt';
import type { Transcriber } from './types';

/**
 * Groq 的 OpenAI 相容端點。和 OPENAI_BASE_URL 一樣寫死，
 * 不讓主機上的 OPENAI_BASE_URL 把音訊與金鑰送到別處。
 */
export const GROQ_BASE_URL = 'https://api.groq.com/openai/v1';

/** 預設轉寫模型；可用 GROQ_TRANSCRIBE_MODEL 覆寫（見 config.ts）。 */
export const GROQ_DEFAULT_TRANSCRIBE_MODEL = 'whisper-large-v3-turbo';

export function createGroqClient(apiKey: string, options: UpstreamClientOptions = {}): OpenAI {
  return new OpenAI({
    apiKey,
    baseURL: GROQ_BASE_URL,
    // 不吃主機的 OPENAI_ORG_ID / OPENAI_PROJECT_ID：Groq 不認得，也可能洩漏別的工具的設定。
    organization: null,
    project: null,
    // 與 OpenAI 相同：單次嘗試、25 秒逾時，重試交給前端 withRetry。
    timeout: OPENAI_TIMEOUT_MS,
    maxRetries: OPENAI_MAX_RETRIES,
    fetch: options.fetch,
  });
}

export function createGroqTranscriber(
  apiKey: string,
  model: string = GROQ_DEFAULT_TRANSCRIBE_MODEL,
  client?: OpenAI,
): Transcriber {
  const groq = client ?? createGroqClient(apiKey);
  return {
    async transcribe({ file, prompt, signal }) {
      try {
        const result = await groq.audio.transcriptions.create(
          {
            file,
            model,
            language: 'zh',
            prompt: buildPrompt(prompt),
            response_format: 'json',
          },
          // 用戶端斷線時取消上游呼叫（契約變更 §8.5：每個轉寫服務都要轉交 signal）。
          { signal },
        );
        return result.text;
      } catch (err) {
        // Groq 免費額度用完時回 429：轉成 UpstreamRateLimitError，app.ts 回 429 並轉傳 Retry-After。
        throw toUpstreamError(err);
      }
    },
  };
}
```

```ts
import { createGroqClient, createGroqTranscriber } from './groqTranscriber';
import {
  createOpenAIClient,
  createOpenAITranscriber,
  type UpstreamClientOptions,
} from './openaiTranscriber';
import type { Transcriber } from './types';

export type TranscribeProvider = 'groq' | 'openai';

/** loadConfig 產生的轉寫服務設定；model 一律是實際使用的模型名稱。 */
export interface TranscriberConfig {
  provider: TranscribeProvider;
  apiKey: string;
  model: string;
}

/** 依設定建出轉寫服務。options.fetch 只給測試注入假上游，server.ts 不傳。 */
export function createTranscriber(
  config: TranscriberConfig,
  options: UpstreamClientOptions = {},
): Transcriber {
  switch (config.provider) {
    case 'groq':
      return createGroqTranscriber(
        config.apiKey,
        config.model,
        createGroqClient(config.apiKey, options),
      );
    case 'openai':
      // OpenAI 固定用 TRANSCRIBE_MODEL；config.model 與它相同，只供啟動訊息顯示。
      return createOpenAITranscriber(config.apiKey, createOpenAIClient(config.apiKey, options));
    default: {
      const unknownProvider: never = config.provider;
      throw new Error(`Unknown transcribe provider: ${String(unknownProvider)}`);
    }
  }
}
```

```ts
import { GROQ_DEFAULT_TRANSCRIBE_MODEL } from './transcriber/groqTranscriber';
import { TRANSCRIBE_MODEL } from './transcriber/openaiTranscriber';

export interface AppConfig {
  transcriber: TranscriberConfig;
  accessKeys: string[];
  allowedOrigins: string[];
  port: number;
}

export const DEFAULT_ALLOWED_ORIGINS: readonly string[] = [
  'http://localhost:5173',
  'https://localhost',
  'capacitor://localhost',
  'app://bundle',
];

export const DEFAULT_PORT = 8787;

/** 短於這個長度的存取金鑰只發警告、不拒絕啟動（各里程碑的人工檢查用 dev-key）。 */
export const MIN_ACCESS_KEY_LENGTH = 16;

/** 逗號分隔、去空白、略過空項，並去除重複（保留第一次出現的順序）。 */
function splitList(value: string | undefined): string[] {
  const items = (value ?? '')
    .split(',')
    .map((item) => item.trim())
    .filter((item) => item.length > 0);
  return [...new Set(items)];
}

/**
 * hono cors 以字串完全比對瀏覽器的 Origin（永遠是小寫、無路徑、無尾斜線）。
 * 像 https://notes.example.com/ 這種值永遠比對不到，CORS 會默默失敗，所以啟動時就擋下。
 */
function assertOrigin(entry: string): void {
  let url: URL | undefined;
  try {
    url = new URL(entry);
  } catch {
    url = undefined;
  }
  if (!url || url.host === '') {
    throw new Error(
      `ALLOWED_ORIGINS entry "${entry}" is not an origin (expected scheme://host[:port])`,
    );
  }
  // http(s) 用 URL 標準的 origin；capacitor://、app:// 這類自訂 scheme 的 origin 是 "null"，改用 scheme://host。
  const origin =
    url.protocol === 'http:' || url.protocol === 'https:'
      ? url.origin
      : `${url.protocol}//${url.host}`;
  if (origin !== entry) {
    throw new Error(
      `ALLOWED_ORIGINS entry "${entry}" is not an origin; use "${origin}" (scheme://host[:port], no path or trailing slash)`,
    );
  }
}

// Only plain decimal digits; Number() alone would also accept '0x1F90', '1e3' and '3000.0'.
function parsePort(raw: string): number {
  return /^\d+$/.test(raw) ? Number(raw) : Number.NaN;
}

/** 去空白後的值；空字串或只有空白視為未設定（Docker --env-file 的 `NAME=` 會給空字串）。 */
function readValue(env: Record<string, string | undefined>, name: string): string | undefined {
  const value = env[name]?.trim();
  return value ? value : undefined;
}

/**
 * 轉寫服務：TRANSCRIBE_PROVIDER 未設定時，有 GROQ_API_KEY 就用 groq，否則有 OPENAI_API_KEY 就用 openai，
 * 兩者都沒有就拒絕啟動。錯誤訊息只列變數名稱，不含金鑰。
 */
function loadTranscriberConfig(env: Record<string, string | undefined>): TranscriberConfig {
  const groqKey = readValue(env, 'GROQ_API_KEY');
  const openaiKey = readValue(env, 'OPENAI_API_KEY');
  const rawProvider = readValue(env, 'TRANSCRIBE_PROVIDER');

  let provider: TranscribeProvider;
  if (rawProvider === undefined) {
    if (groqKey) provider = 'groq';
    else if (openaiKey) provider = 'openai';
    else {
      throw new Error(
        'No transcription API key: set GROQ_API_KEY (free key at https://console.groq.com/keys) or OPENAI_API_KEY',
      );
    }
  } else {
    const normalized = rawProvider.toLowerCase();
    if (normalized !== 'groq' && normalized !== 'openai') {
      throw new Error(`TRANSCRIBE_PROVIDER must be "groq" or "openai", got "${rawProvider}"`);
    }
    provider = normalized;
  }

  if (provider === 'groq') {
    if (!groqKey) throw new Error('GROQ_API_KEY is required when TRANSCRIBE_PROVIDER=groq');
    return {
      provider,
      apiKey: groqKey,
      model: readValue(env, 'GROQ_TRANSCRIBE_MODEL') ?? GROQ_DEFAULT_TRANSCRIBE_MODEL,
    };
  }

  if (!openaiKey) throw new Error('OPENAI_API_KEY is required when TRANSCRIBE_PROVIDER=openai');
  return { provider, apiKey: openaiKey, model: TRANSCRIBE_MODEL };
}

export function loadConfig(env: Record<string, string | undefined>): AppConfig {
  const transcriber = loadTranscriberConfig(env);

  const accessKeys = splitList(env['ACCESS_KEYS']);
  if (accessKeys.length === 0) {
    throw new Error('ACCESS_KEYS is required (comma-separated list of access keys)');
  }
  // auth 只接受不含空白的 Bearer token，含空白的金鑰啟動後永遠驗證不過，所以啟動時就擋下（訊息不含金鑰本身）。
  accessKeys.forEach((key, index) => {
    if (/\s/.test(key)) {
      throw new Error(
        `ACCESS_KEYS entry ${index + 1} contains whitespace; access keys must not contain spaces`,
      );
    }
  });

  const origins = splitList(env['ALLOWED_ORIGINS']);
  origins.forEach(assertOrigin);
  const allowedOrigins = origins.length > 0 ? origins : [...DEFAULT_ALLOWED_ORIGINS];

  const rawPort = env['PORT']?.trim();
  const port = rawPort ? parsePort(rawPort) : DEFAULT_PORT;
  if (!Number.isInteger(port) || port < 1 || port > 65535) {
    throw new Error(`PORT must be an integer between 1 and 65535, got "${rawPort}"`);
  }

  return { transcriber, accessKeys, allowedOrigins, port };
}

/**
 * 錯誤金鑰的嘗試不計入限流：限流依「已通過驗證」的金鑰計數，而依 IP 限制在反向代理後會讓所有人共用一個桶。
 * 所以金鑰本身必須夠長、夠隨機。回傳啟動時要印出的警告；訊息不含金鑰本身。
 */
export function accessKeyWarning(accessKeys: readonly string[]): string | undefined {
  const short = accessKeys.filter((key) => key.length < MIN_ACCESS_KEY_LENGTH).length;
  if (short === 0) return undefined;
  return (
    `[config] ${short} of ${accessKeys.length} ACCESS_KEYS ${short === 1 ? 'is' : 'are'} ` +
    `shorter than ${MIN_ACCESS_KEY_LENGTH} characters. ` +
    'Wrong-key attempts are not rate-limited, so short keys can be guessed online; ' +
    'use long random keys, e.g. node -e "console.log(crypto.randomUUID())"'
  );
}
```

````markdown
Hono + Node 的小型 API：接收前端錄音切好的單段音訊，交給轉寫服務（預設 Groq `whisper-large-v3-turbo`，也可改用 OpenAI `gpt-4o-mini-transcribe`），並把結果轉成繁體中文（台灣）後回傳。

## API

| 方法與路徑 | 驗證 | 說明 |
|---|---|---|
| `GET /health` | 不需要 | 回 `200 { "ok": true }`，供設定頁「測試連線」使用 |
| `POST /transcribe` | `Authorization: Bearer <存取金鑰>` | `multipart/form-data`：`audio`（檔案，≤ 5MB）、`seq`（整數 ≥ 1）、`prompt`（字串，可省略）→ `200 { "seq": 1, "text": "..." }` |

錯誤一律回 `{ "error": "<code>" }`：

| 狀態碼 | `error` | 何時發生 |
|---|---|---|
| 400 | `bad_request` | 缺 `audio`、`audio` 為空或不是檔案、`seq` 不是正整數（或超過 `Number.MAX_SAFE_INTEGER`）、`prompt` 不是字串（例如以檔案送出）、body 不是 multipart |
| 401 | `unauthorized` | 缺少或錯誤的存取金鑰 |
| 404 | `bad_request` | 未知路徑或方法（例如 `GET /transcribe`、後端網址多了路徑前綴） |
| 413 | `payload_too_large` | 音訊超過 5MB |
| 429 | `rate_limited` | 同一把金鑰每分鐘超過 60 次，或轉寫服務（Groq／OpenAI）回 429。回應帶 `Retry-After`（秒）：上游 429 時轉傳上游的值，上游沒給就帶 `10` |
| 500 | `upstream_error` | 伺服器未預期的錯誤 |
| 502 | `upstream_error` | 轉寫服務失敗（429 以外，例如金鑰錯誤、服務故障、逾時） |

部署平台或反向代理自己產生的錯誤頁（例如逾時的 502／504）不經過本程式，可能不是 JSON；用戶端應以狀態碼為準。

CORS：只允許 `ALLOWED_ORIGINS` 內的來源，並公開 `Retry-After` 標頭給瀏覽器讀取。

## 轉寫服務

| `TRANSCRIBE_PROVIDER` | 需要的金鑰 | 模型 |
|---|---|---|
| `groq` | `GROQ_API_KEY` | `whisper-large-v3-turbo`（可用 `GROQ_TRANSCRIBE_MODEL` 覆寫） |
| `openai` | `OPENAI_API_KEY` | `gpt-4o-mini-transcribe`（固定） |

| 名稱 | 必填 | 說明 |
|---|---|---|
| `TRANSCRIBE_PROVIDER` | 否 | `groq` 或 `openai`（不分大小寫）；不填則依上節規則自動選擇；其他值拒絕啟動 |
| `GROQ_API_KEY` | 二擇一 | Groq API 金鑰；使用 Groq 時必填 |
| `GROQ_TRANSCRIBE_MODEL` | 否 | Groq 轉寫模型，預設 `whisper-large-v3-turbo` |
| `OPENAI_API_KEY` | 二擇一 | OpenAI API 金鑰；使用 OpenAI 時必填 |
| `ACCESS_KEYS` | 是 | 存取金鑰，逗號分隔。每把請用至少 16 字元的隨機值（例如 `node -e "console.log(crypto.randomUUID())"`）；較短的金鑰仍可啟動，但會印出警告 |
| `ALLOWED_ORIGINS` | 否 | CORS 允許來源，逗號分隔；預設 `http://localhost:5173,https://localhost,capacitor://localhost,app://bundle`。每項只能是 `scheme://host[:port]`（例如 `https://notes.example.com`），不可有路徑或結尾斜線；格式不對會拒絕啟動 |
| `PORT` | 否 | 監聽埠，預設 `8787` |

伺服器固定連 `https://api.groq.com/openai/v1`（Groq）或 `https://api.openai.com/v1`（OpenAI）：OpenAI SDK 平常會讀的 `OPENAI_BASE_URL`、`OPENAI_ORG_ID`、`OPENAI_PROJECT_ID` 一律忽略，避免主機上為別的工具設定的值把音訊與金鑰送到別處。

## 本機執行

在 repo 根目錄（Windows 用 Git Bash）：

```bash
npm install
cp apps/api/.env.example apps/api/.env   # 填入 GROQ_API_KEY（或 OPENAI_API_KEY）與自訂 ACCESS_KEYS
npm run dev -w @oc/api                   # tsx watch，改檔自動重啟；會自動讀 apps/api/.env
```

注意：Node 的 `--env-file` 不會覆寫已存在的環境變數。若 shell 或 Windows 使用者環境變數已設定 `GROQ_API_KEY`、`OPENAI_API_KEY` 等同名變數，會以那個值為準、忽略 `.env`；例如主機上只有 `OPENAI_API_KEY`、`.env` 填了 `GROQ_API_KEY` 時，仍會選 Groq，但主機上的 `TRANSCRIBE_PROVIDER=openai` 會蓋過 `.env`。要確定使用 `.env` 的值，請這樣啟動：

```bash
(unset TRANSCRIBE_PROVIDER GROQ_API_KEY GROQ_TRANSCRIBE_MODEL OPENAI_API_KEY ACCESS_KEYS ALLOWED_ORIGINS PORT; npm run dev -w @oc/api)
```

驗證：

```bash
curl http://localhost:8787/health
curl -X POST http://localhost:8787/transcribe \
  -H "Authorization: Bearer <你的存取金鑰>" \
  -F seq=1 -F "audio=@/path/to/clip.webm;type=audio/webm"
```

前端「設定」頁的後端網址填 `http://localhost:8787`，存取金鑰填 `ACCESS_KEYS` 其中一把。

## Docker

Build context 必須是 repo 根目錄（映像需要 `packages/shared`）：

```bash
docker build -f apps/api/Dockerfile -t open-copilot-api .
docker run --rm -p 8787:8787 --env-file apps/api/.env open-copilot-api
```

`--env-file` 內若設定了 `PORT`，`-p` 的容器埠要跟著改。

同一份 `.env` 要給 `docker run --env-file` 用時，值不可加引號：Node 的 `--env-file`（`npm run dev`）會去掉引號，Docker 會原樣保留，例如 `GROQ_API_KEY="gsk_..."` 進到容器就帶著引號，每次呼叫轉寫服務都會回 502 `upstream_error`。留空的 `NAME=` 視為未設定。

## 部署注意

- 放在 HTTPS 之後（Fly.io／Render 預設提供）；存取金鑰走 `Authorization` 標頭，不可用明文 HTTP 對外。
- 錯誤金鑰的嘗試不計入限流（限流依已通過驗證的金鑰計數），所以存取金鑰必須是長的隨機值，不能用 `dev-key` 這類好猜的字串對外。
- `ALLOWED_ORIGINS` 要加上網頁正式網域。
- 限流計數存在記憶體，只適用單一實例；要水平擴充需改成共用儲存（例如 Redis）。
- 每個 `/transcribe` 只呼叫轉寫服務一次（不重試）、單次逾時 25 秒，重試交給前端（前端每個請求 30 秒逾時）。用戶端斷線或逾時放棄時，進行中的上游呼叫會一併取消，不會和前端的重試疊在一起。反向代理的請求逾時請設在 30 秒以上，否則代理會比本程式先放棄。
- 要加新的轉寫服務時，實作 `src/transcriber/types.ts` 的 `Transcriber` 介面（把 `signal` 轉給上游呼叫，斷線時才會取消；上游 429 用 `src/transcriber/errors.ts` 的 `toUpstreamError` 轉換），在 `src/transcriber/createTranscriber.ts` 加一個 provider，並擴充 `src/config.ts` 的 `TRANSCRIBE_PROVIDER`。
````
