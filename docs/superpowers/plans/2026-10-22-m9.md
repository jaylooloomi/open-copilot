# M9 PWA 與手機分享網址 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓網頁版成為可安裝、可離線開啟的 PWA（只在一般瀏覽器註冊 service worker），並讓 `npm run prototype -- --share` 透過 Cloudflare quick tunnel 產生手機可用的 HTTPS 分享網址與 QR code。

**Architecture:** `apps/web/vite.config.ts` 加入 `vite-plugin-pwa`（`generateSW`、`autoUpdate`、`injectRegister: false`），manifest 與 workbox 設定集中在匯出的 `PWA_OPTIONS`；`/api` 與跨網域請求用 network-only，不進快取。圖示由 `apps/web/icons/*.svg` 經 `sharp` 產生 PNG 並 commit，測試比對 PNG 與 SVG 是否一致。`src/main.tsx` 只在 `detectPlatformKind()` 判定為 `web` 時才透過 `virtual:pwa-register` 註冊；Electron（`app://`）與 Capacitor 都不註冊。啟動器 `scripts/prototype.mjs` 加入 `--share`：用 npm 套件 `cloudflared` 提供的執行檔啟動 `cloudflared tunnel --url http://localhost:5173`，從 log 解析出 `https://*.trycloudflare.com`，經過通道檢查 `/api/health` 後，印出 `#oc-setup`（`apiBaseUrl = <tunnel>/api`）網址、QR code 與公開網址警告；Vite `server.allowedHosts` 允許 `.trycloudflare.com`。

**Tech Stack:** Vite 7、vite-plugin-pwa 2.0（Workbox 7.4）、sharp 0.35、tsx、npm 套件 `cloudflared` 0.7、`qrcode` 1.5、Vitest 3、Playwright 1.64、node:test。

## 設計決策

1. **分享模式用 dev server，不註冊 service worker。** 設計 §4 指定 tunnel 指向 `http://localhost:5173`。vite-plugin-pwa 在 dev 模式下 `virtual:pwa-register` 是空函式（`devOptions.enabled` 維持預設 `false`），所以分享網址不會有 service worker，也不會在使用者的 `localhost:5173` 留下會快取舊頁面的 SW。PWA 的離線與 SW 驗收改在 `vite preview`（4173）的建置版上跑。
2. **真機安裝 PWA 用建置版。** `vite preview` 會繼承 `server.allowedHosts` 與 `server.proxy`，所以 README 寫明手動步驟：`npm run build -w @oc/web && npm run preview -w @oc/web`，另開終端機 `npx cloudflared tunnel --url http://localhost:4173`，用手機開啟印出的網址安裝。這是 manualItems。
3. **自己 spawn cloudflared，不用套件的 `Tunnel` 類別。** 只從 `cloudflared` 套件取 `bin` 與 `install`（第一次缺執行檔時下載），通道程序和後端、網頁伺服器一起交給既有的 `supervise()`：任何一個結束，其他也跟著停止，Ctrl+C 一起收掉。
4. **等到「網址」和「Registered tunnel connection」都出現才去連。** 太早查詢新的 `*.trycloudflare.com` 子網域，Windows 可能快取 NXDOMAIN。通道就緒後再經過通道檢查 `/api/health`（60 秒）；一般模式連不到只警告（手機通常仍能開），`--check` 模式則以 exit code 1 結束。
5. **未知選項直接報錯。** `--shar` 這類錯字不應默默啟動一個沒有分享的工作階段，`parseFlags` 在做任何事之前就丟錯。
6. **`injectRegister: false`**：避免 plugin 在 `index.html` 注入 `registerSW.js`，否則 Electron 與 Android 也會註冊。
7. **workbox 路由函式必須自給自足。** `generateSW` 會把 `runtimeCaching[].urlPattern` 的原始碼複製進 `sw.js`，所以 `isNetworkOnlyRequest` 不能引用外部常數；測試用 `new Function` 重建它來驗證。
8. **PNG 一致性用像素比對。** 測試重新把 SVG 轉成 PNG，與 commit 的 PNG 比較每個通道的平均差異（< 2），容許不同平台光柵化的捨入差，但 SVG 一改就會失敗，提醒執行 `npm run icons -w @oc/web`。
9. **`npm run e2e` 同時跑 PWA e2e。** `playwright.config.ts` 改成兩個 project、兩個 webServer（dev 5173、`npm run build && npm run preview` 4173），CI 的 `npm run e2e` 不必改 workflow 就會包含 PWA 驗收。
10. **CI 的 `npm ci` 會下載 cloudflared 執行檔**（`cloudflared` 套件的 postinstall），這是設計 §4「以 npm devDependency 安裝」的代價；CI 不會啟動通道。

// @vitest-environment node
// (sharp returns Node Buffers; under jsdom Uint8Array comes from another realm.)
import { existsSync } from 'node:fs';
import { join } from 'node:path';
import sharp from 'sharp';
import { describe, expect, it } from 'vitest';
import { ICON_OUTPUT_DIR, ICONS, renderIcon } from '../scripts/icons';

async function rgba(input: Buffer | string) {
  const { data, info } = await sharp(input).ensureAlpha().raw().toBuffer({ resolveWithObject: true });
  return { data, width: info.width, height: info.height };
}

describe('PWA icons', () => {
  it('lists the 192, 512 and maskable 512 icons from the two SVG sources', () => {
    expect(ICONS.map((icon) => [icon.source, icon.output, icon.size])).toEqual([
      ['icon.svg', 'icon-192.png', 192],
      ['icon.svg', 'icon-512.png', 512],
      ['icon-maskable.svg', 'icon-maskable-512.png', 512],
    ]);
  });

  it.each(ICONS)(
    'commits $output at $size px, matching its SVG source',
    async (icon) => {
      const file = join(ICON_OUTPUT_DIR, icon.output);
      expect(existsSync(file), `${file} is missing: run npm run icons -w @oc/web`).toBe(true);
      const committed = await rgba(file);
      const fresh = await rgba(await renderIcon(icon));
      expect([committed.width, committed.height]).toEqual([icon.size, icon.size]);
      let diff = 0;
      for (let i = 0; i < fresh.data.length; i += 1) diff += Math.abs(fresh.data[i]! - committed.data[i]!);
      // Rasterizers round differently across platforms by a step or so; an edited SVG differs far more.
      expect(diff / fresh.data.length, 'run npm run icons -w @oc/web and commit the PNGs').toBeLessThan(2);
    },
    30_000,
  );

  it('fills the maskable icon to the corners (launchers crop it to their own shape)', async () => {
    const icon = ICONS.find((entry) => entry.output === 'icon-maskable-512.png')!;
    const { data, width } = await rgba(await renderIcon(icon));
    const alphaAt = (x: number, y: number) => data[(y * width + x) * 4 + 3];
    expect([alphaAt(0, 0), alphaAt(width - 1, 0), alphaAt(0, width - 1), alphaAt(width - 1, width - 1)]).toEqual([
      255, 255, 255, 255,
    ]);
  });
});

建立 `apps/web/scripts/icons.ts`：

```ts
// PWA icons (add-ons design 4): PNGs rendered from the SVG sources in apps/web/icons and
// committed under apps/web/public/icons. src/pwaIcons.test.ts checks they are up to date.
import { mkdir, readFile, writeFile } from 'node:fs/promises';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import sharp from 'sharp';

export const WEB_DIR = fileURLToPath(new URL('..', import.meta.url));
export const ICON_SOURCE_DIR = join(WEB_DIR, 'icons');
export const ICON_OUTPUT_DIR = join(WEB_DIR, 'public', 'icons');

export interface IconSpec {
  /** SVG file in apps/web/icons. */
  source: string;
  /** PNG file in apps/web/public/icons (served as /icons/<output>). */
  output: string;
  size: number;
}

export const ICONS: readonly IconSpec[] = [
  { source: 'icon.svg', output: 'icon-192.png', size: 192 },
  { source: 'icon.svg', output: 'icon-512.png', size: 512 },
  { source: 'icon-maskable.svg', output: 'icon-maskable-512.png', size: 512 },
];

export async function renderIcon(icon: IconSpec): Promise<Buffer> {
  const svg = await readFile(join(ICON_SOURCE_DIR, icon.source));
  // 144 dpi draws the 512-unit SVG at 1024 px; scaling down from there gives clean edges.
  return sharp(svg, { density: 144 })
    .resize(icon.size, icon.size)
    .png({ compressionLevel: 9 })
    .toBuffer();
}

/** Writes every PNG and returns their paths. */
export async function writeIcons(): Promise<string[]> {
  await mkdir(ICON_OUTPUT_DIR, { recursive: true });
  const written: string[] = [];
  for (const icon of ICONS) {
    const path = join(ICON_OUTPUT_DIR, icon.output);
    await writeFile(path, await renderIcon(icon));
    written.push(path);
  }
  return written;
}
```

import {
  createBrowserFileSaver,
  createIndexedDbStorage,
  openAppDb,
  type FileSaver,
  type Platform,
} from '@oc/core';
import { installBackgroundMicGuard } from './backgroundMicGuard';
import { createCapacitorFileSaver } from './capacitorFileSaver';
import { createDesktopFileSaver } from './desktopFileSaver';

/** Which shell runs this page: a plain browser, Electron (M4) or the Capacitor Android app (M5). */
export type PlatformKind = 'web' | 'desktop' | 'android';

export function detectPlatformKind(
  location: Pick<Location, 'protocol'> = window.location,
): PlatformKind {
  if (Capacitor.isNativePlatform()) return 'android';
  // apps/desktop serves the page from app://bundle and its preload exposes window.ocDesktop.
  if (window.ocDesktop || location.protocol === 'app:') return 'desktop';
  return 'web';
}

/** Web, Electron (M4) and the Capacitor Android app (M5). */
export async function selectPlatform(): Promise<Platform> {
  const db = await openAppDb();
  const isCapacitorApp = detectPlatformKind() === 'android';
  // Android silences a backgrounded app's microphone; end the recording there instead.
  if (isCapacitorApp) installBackgroundMicGuard();
  return {
    storage: createIndexedDbStorage(db),
    fileSaver: isCapacitorApp ? createCapacitorFileSaver() : selectFileSaver(),
    // Android's WebView has no window.print(), so the app hides 匯出 PDF.
    canPrint: !isCapacitorApp,
  };
}

function selectFileSaver(): FileSaver {
  // apps/desktop's preload script exposes window.ocDesktop; browsers do not have it.
  // Read once at startup: preload runs before page scripts, so the bridge already exists.
  const desktop = window.ocDesktop;
  return desktop ? createDesktopFileSaver(desktop) : createBrowserFileSaver();
}

/**
 * Registers the PWA service worker (add-ons design 4), but only in a plain browser: the Electron
 * app (app://) and the Android app (Capacitor) ship their files themselves. Resolves to whether
 * it registered. A failed registration only warns; the app works without a service worker.

export async function registerServiceWorker(

  nav: object = navigator,

  if (kind !== 'web' || !('serviceWorker' in nav)) return false;

export const LAUNCHER_FLAGS = ['--no-open', '--check', '--share'];

/**
 * Launcher options. Unknown flags throw before anything starts, so a typo such as --shar never
 * silently runs a session without the share URL.
 * @returns {{ checkOnly: boolean, openInBrowser: boolean, share: boolean }}
 */
export function parseFlags(argv) {
  const unknown = argv.filter((arg) => !LAUNCHER_FLAGS.includes(arg));
  if (unknown.length > 0) {
    throw new Error(
      `[prototype] 不認得的選項：${unknown.join(' ')}（可用的選項：${LAUNCHER_FLAGS.join('、')}）`,
    );
  }
  const checkOnly = argv.includes('--check');
  return {
    checkOnly,
    openInBrowser: !checkOnly && !argv.includes('--no-open'),
    share: argv.includes('--share'),
  };
}

export const SHARE_WARNING =
  '[prototype] 注意：分享網址是公開的，請只在測試時開啟，用完按 Ctrl+C 關閉；後端仍然需要存取金鑰。';

/** The quick tunnel URL cloudflared prints in a box; api.trycloudflare.com is its own API. */
export const TUNNEL_URL_PATTERN = /https:\/\/(?!api\.)[a-z0-9-]+\.trycloudflare\.com/;
/** Logged once an edge connection is up; querying the new hostname before that risks a cached NXDOMAIN. */
export const TUNNEL_CONNECTED_PATTERN = /Registered tunnel connection/i;

export function findTunnelUrl(line) {
  return TUNNEL_URL_PATTERN.exec(line)?.[0] ?? null;
}

/**
 * Reads cloudflared's output. `ready` resolves with the tunnel URL once the URL and a registered
 * connection have both been logged, or with null when every stream ends, `timeoutMs` passes or
 * cancel() is called. tail() returns the last `tailLines` non-blank lines for error messages.
 * The streams keep being read after `ready`, so cloudflared never blocks on a full pipe.
 */
export function watchTunnel(streams, { timeoutMs = 90_000, tailLines = 20 } = {}) {
  const tail = [];
  let url = null;
  let connected = false;
  let settled = false;
  let open = streams.length;
  let resolveReady;
  const ready = new Promise((resolve) => {
    resolveReady = resolve;
  });
  const finish = (value) => {
    if (settled) return;
    settled = true;
    clearTimeout(timer);
    resolveReady(value);
  };
  const timer = setTimeout(() => finish(null), timeoutMs);
  const onLine = (line) => {
    if (line.trim() === '') return;
    tail.push(line);
    if (tail.length > tailLines) tail.shift();
    url ??= findTunnelUrl(line);
    if (TUNNEL_CONNECTED_PATTERN.test(line)) connected = true;
    if (url && connected) finish(url);
  };
  for (const stream of streams) {
    let buffer = '';
    stream.setEncoding('utf8');
    stream.on('data', (chunk) => {
      buffer += chunk;
      const lines = buffer.split(/\r?\n/);
      buffer = lines.pop() ?? '';
      for (const line of lines) onLine(line);
    });
    stream.on('end', () => {
      if (buffer !== '') onLine(buffer);
      buffer = '';
    });
    stream.on('close', () => {
      open -= 1;
      if (open === 0) finish(null);
    });
  }
  return { ready, tail: () => [...tail], cancel: () => finish(null) };
}

/** The phone's link: the tunnel origin with #oc-setup pointing at <tunnel>/api (same origin). */
export function shareSetupUrl(tunnelOrigin, accessKey) {
  return setupUrl(tunnelOrigin, { apiBaseUrl: `${tunnelOrigin}/api`, accessKey });
}

/** A QR code made of block characters, for the phone camera. `toString` is injected by tests. */
export function renderQr(text, toString = (value, options) => QRCode.toString(value, options)) {
  return toString(text, { type: 'terminal', small: true });
}

 * it); downloads it now if it is missing. `load`, `exists` and `log` are injected by tests.
 */

} = {}) {

  }
  return bin;
}
