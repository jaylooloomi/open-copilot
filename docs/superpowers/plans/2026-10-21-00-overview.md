## 3. Monorepo 結構與套件名稱

```
package.json                 # private, "workspaces": ["packages/*", "apps/*"]
tsconfig.base.json           # strict, moduleResolution "bundler", jsx "react-jsx", target ES2022
.gitignore                   # node_modules, dist, coverage, playwright-report, test-results, .env, apps/web/android/app/build
packages/shared   → @oc/shared   # 純 TS，無執行期依賴
packages/core     → @oc/core     # React 元件與邏輯；依賴 @oc/shared
apps/web          → @oc/web      # Vite 入口；M5 起同時是 Capacitor 專案
apps/desktop      → @oc/desktop  # Electron（CommonJS）
apps/api          → @oc/api      # Hono 後端（ESM，用 tsx 執行）
```

- 工作區套件以**原始碼**互相引用：`packages/*/package.json` 設 `"type": "module"`、`"main": "src/index.ts"`、`"types": "src/index.ts"`、`"exports": { ".": "./src/index.ts" }`。Vite、Vitest、tsx 都能直接吃 TS 原始碼。
- 每個套件的 scripts：`"test": "vitest run"`、`"typecheck": "tsc --noEmit"`。
- 根 scripts：`"test": "npm run test --workspaces --if-present"`、`"typecheck": "npm run typecheck --workspaces --if-present"`。
- 執行單一測試檔：`npm test -w @oc/core -- src/notes/noteStore.test.ts`
- 測試與原始碼同目錄：`src/**/*.test.ts(x)`。`packages/core` 的 Vitest 使用 `environment: 'jsdom'`，`setupFiles: ['./src/test/setup.ts']`，setup 內 `import '@testing-library/jest-dom/vitest'` 與 `import 'fake-indexeddb/auto'`。

### 匯出與複製（M2）
- `export/filename.ts`：`toFilename(title: string, ext: 'md'|'docx'|'txt'|'pdf'): string`（去除 `\/:*?"<>|` 與控制字元、trim、截 80 字；空白時用 `未命名筆記`）。
- `export/toMarkdown.ts`：`toMarkdown(note: Note): string` — 開頭 `# 標題`（標題空則省略）；標題節點 `#`/`##`/`###` 往下推一級（`##`、`###`、`####`）；粗體 `**`、斜體 `*`、底線 `<u></u>`；字色、螢光筆、對齊捨棄；清單 `- ` / `1. `。
- `export/toTxt.ts`：`toTxt(note: Note): string` — 第一行標題、空行、內文；清單保留 `- ` / `1. ` 前綴；無任何格式。
- `export/toDocx.ts`：`toDocx(note: Note): Promise<Blob>` — 保留粗斜底線、字色、螢光筆（shading）、對齊、標題層級、項目／編號清單。
- `export/toHtml.ts`：`toHtml(note: Note): string`（`generateHTML(content, createExtensions())` + 標題 `<h1>`），供 PDF 與複製使用。
- `export/printPdf.ts`：`printPdf(note: Note): void` — 隱藏 iframe 寫入 HTML 後 `contentWindow.print()`。
- `export/exportNote.ts`：`exportNote(note, format: 'md'|'docx'|'txt'|'pdf', platform: Platform): Promise<void>`。
- `export/copyNote.ts`：`copyNote(note): Promise<void>` — 優先 `navigator.clipboard.write` 寫 `text/html` + `text/plain`，失敗改 `writeText(toTxt(note))`。
- 匯出中未知節點：輸出其文字內容；M3b 的 `transcriptGap` 節點一律輸出 `[未轉寫片段]`。

### 後端（M3a）`apps/api`
- `src/config.ts`：`loadConfig(env: Record<string, string | undefined>)` → `{ transcriber: { provider: 'groq' | 'openai'; apiKey: string; model: string }; accessKeys: string[]; allowedOrigins: string[]; port: number; ai: { apiKey: string; model: string } | null }`（M6；`ai` 為 M11：有 `GROQ_API_KEY` 就啟用，與 `TRANSCRIBE_PROVIDER` 無關，模型預設 `openai/gpt-oss-120b`，`GROQ_LLM_MODEL` 覆寫；沒有 Groq 金鑰時為 `null`，不拒絕啟動）。`TRANSCRIBE_PROVIDER` 可為 `groq`／`openai`；未設定時有 `GROQ_API_KEY` 用 `groq`，否則有 `OPENAI_API_KEY` 用 `openai`，兩者皆無 throw；指定的 provider 缺對應金鑰 throw。Groq 模型預設 `whisper-large-v3-turbo`（`GROQ_TRANSCRIBE_MODEL` 覆寫），OpenAI 固定 `gpt-4o-mini-transcribe`。缺 `ACCESS_KEYS` 時 throw。`ALLOWED_ORIGINS` 預設 `http://localhost:5173,https://localhost,capacitor://localhost,app://bundle`；`PORT` 預設 `8787`。
- `src/transcriber/types.ts`：`interface Transcriber { transcribe(input: { file: File; prompt: string; signal?: AbortSignal }): Promise<string> }`。
- `src/transcriber/prompt.ts`（M6）：`buildPrompt(previousText)` = 前綴 `以下是繁體中文的語音內容。` + 前文去空白後的最後 60 個字（`PROMPT_TAIL_CHARS`；前綴加 60 字最多 219 個 UTF-8 位元組，不超過 Whisper 的 224 tokens）；兩種轉寫服務共用。
- `src/transcriber/errors.ts`（M6）：`UpstreamRateLimitError { retryAfterSeconds }`、`toUpstreamError(err)`（上游 SDK 的 429 → `UpstreamRateLimitError`，`Retry-After` 取整數秒並限制在 1–300 秒，缺少或看不懂時為 10）。
- `src/transcriber/openaiTranscriber.ts`：`createOpenAITranscriber(apiKey: string, client?: OpenAI): Transcriber`；模型 `gpt-4o-mini-transcribe`、`language: 'zh'`、prompt 用 `buildPrompt`。
- `src/transcriber/groqTranscriber.ts`（M6）：`createGroqTranscriber(apiKey: string, model?: string, client?: OpenAI): Transcriber`；OpenAI SDK、`baseURL: https://api.groq.com/openai/v1`、`language: 'zh'`、prompt 用 `buildPrompt`。
- `src/transcriber/createTranscriber.ts`（M6）：`createTranscriber(config.transcriber, options?: { fetch }): Transcriber`，依 provider 選實作；`options.fetch` 只給測試注入假上游。provider 為 openai 時 model 必須是 `gpt-4o-mini-transcribe`，否則丟錯（防止覆寫被默默忽略）。
- `src/text/toTraditional.ts`：`toTraditional(text: string): string`（opencc-js `cn` → `tw`；`opencc-js@^1.4` 自帶型別，不需 d.ts）。
- `src/middleware/auth.ts`：`bearerAuth(accessKeys: string[])`（`crypto.timingSafeEqual` 比對；失敗 401 `{ error: 'unauthorized' }`），通過後 `c.set('accessKey', key)`。
- `src/middleware/rateLimit.ts`：`rateLimit({ limit, windowMs, now = Date.now })` 固定視窗、依 accessKey 計數；超過回 429 `{ error: 'rate_limited' }` 與 `Retry-After`（秒，無條件進位）。
- `src/app.ts`：`createApp({ transcriber, assistant?, accessKeys, allowedOrigins, now? }): Hono`（`assistant?: NoteAssistant | null` 為 M11）。路由：`GET /health`（不驗證）→ `{ ok: true }`；`POST /transcribe`（CORS → auth → rateLimit → body limit）。multipart 欄位 `audio`（File）、`seq`（整數 ≥ 1）、`prompt`（可空）。超過 `MAX_AUDIO_BYTES` → 413 `payload_too_large`；欄位錯誤 → 400 `bad_request`；轉寫服務丟 `UpstreamRateLimitError` → 429 `rate_limited` 加 `Retry-After`（M6）；其他轉寫錯誤 → 502 `upstream_error`。成功 → `{ seq, text: toTraditional(text.trim()) }`。
- `src/ai/types.ts`（M11）：`interface NoteAssistant { summarize(input: AiInput): Promise<string>; extractTodos(input: AiInput): Promise<string[]> }`，`AiInput = { title: string; text: string; signal?: AbortSignal }`；`AiConfig = { apiKey: string; model: string }`。
- `src/ai/request.ts`（M11）：`parseAiRequest(raw: unknown): AiRequest | 'bad_request' | 'payload_too_large'`（title、text 必須是字串；text 空白 → `bad_request`；超過 `AI_MAX_TEXT_CHARS` 字 → `payload_too_large`）。
- `src/ai/output.ts`（M11）：`AiOutputError`、`normalizeSummary(content)`、`parseTodoItems(content)`（JSON `{ items: string[] }`；去空白、去開頭清單符號、略過空白與重複、最多 `MAX_TODO_ITEMS` = 50）。
- `src/ai/groqAssistant.ts`（M11）：`GROQ_DEFAULT_LLM_MODEL = 'openai/gpt-oss-120b'`、`createGroqLlmClient(apiKey, options?)`（`baseURL` 寫死 Groq、逾時 `AI_UPSTREAM_TIMEOUT_MS`、不重試）、`createGroqAssistant(apiKey: string, model?: string, client?: OpenAI): NoteAssistant`；`/ai/todos` 用 `response_format: { type: 'json_object' }`；上游 429 用 `toUpstreamError`。
- AI 路由（M11）：`POST /ai/summary`、`POST /ai/todos`（CORS → auth → AI 限流（兩端點共用、與 `/transcribe` 分開，每把金鑰每分鐘 `RATE_LIMIT_PER_MINUTE`）→ body 上限 `AI_MAX_TEXT_CHARS × 4 + 64 KiB` → 沒有 assistant 時 503 `ai_unavailable` → JSON 驗證）。400 `bad_request`、413 `payload_too_large`；上游錯誤的對應與 `/transcribe` 相同（429 帶 `Retry-After`，其他與輸出格式錯誤皆 502）；成功 → `{ summary: toTraditional(summary) }`／`{ items: items.map(toTraditional) }`。
- `src/server.ts`：讀 env、`serve({ fetch: app.fetch, port })`。
- `apps/api/Dockerfile`：以 repo 根目錄為 build context（`docker build -f apps/api/Dockerfile .`），用 tsx 執行。
- `apps/api/.env.example`：列出 `TRANSCRIBE_PROVIDER`、`GROQ_API_KEY`、`GROQ_TRANSCRIBE_MODEL`、`GROQ_LLM_MODEL`（M11）、`OPENAI_API_KEY`、`ACCESS_KEYS`、`ALLOWED_ORIGINS`、`PORT`（金鑰類全部留空）。

### 錄音（M3b）`packages/core/src`
- `settings/settingsStore.ts`：`interface Settings { apiBaseUrl: string; accessKey: string }`；`loadSettings(): Settings`、`saveSettings(s: Settings): void`（localStorage key `oc.settings`）、`isConfigured(s): boolean`；`settings/useSettings.ts`。
- `components/SettingsDialog.tsx`：後端網址、存取金鑰、「測試連線」（呼叫 `health()`），ActionBar 右上齒輪開啟。
- `api/apiClient.ts`：`class ApiError extends Error { status: number; retryAfterMs?: number }`（網路錯誤 status = 0）；`createApiClient({ baseUrl, accessKey, fetchImpl = fetch })` → `{ health(): Promise<boolean>; transcribe(input: { audio: Blob; seq: number; prompt: string; filename: string }): Promise<TranscribeResponse> }`。
- `recording/pickMimeType.ts`：`pickMimeType(isSupported?: (t: string) => boolean): string | undefined`，候選依序 `audio/webm;codecs=opus`、`audio/mp4`；`extensionFor(mimeType): 'webm'|'mp4'`。
- `recording/rms.ts`：`computeRms(samples: Float32Array): number`。
- `recording/segmentPolicy.ts`：`class SegmentPolicy { constructor(opts?: { minMs?: 4000; maxMs?: 8000; silenceMs?: 300; threshold?: 0.01 }); start(nowMs: number): void; update(nowMs: number, rms: number): 'continue' | 'cut' }`；切段後呼叫端再 `start(nowMs)`。
- `recording/segmentRecorder.ts`：`class SegmentRecorder`，建構參數 `{ stream: MediaStream; mimeType?: string; onSegment(seg: { seq: number; blob: Blob }): void; onInterrupted(): void; policy?: SegmentPolicy; now?: () => number; createAudioContext?: () => AudioContext; pollMs?: 50 }`；方法 `start()`、`stop(): Promise<void>`。每段重開一個 `MediaRecorder`（不用 timeslice）；seq 從 1 起；`stream` 任一 track `ended` 時呼叫 `onInterrupted` 並送出已錄部分。
- `recording/orderedBuffer.ts`：`class OrderedBuffer<T> { constructor(firstSeq = 1); put(seq: number, value: T): T[] }`（回傳此刻可依序釋出的項目）。
- `recording/retry.ts`：`withRetry<T>(fn: () => Promise<T>, opts?: { delaysMs?: number[]; sleep?: (ms: number) => Promise<void> }): Promise<T>`；預設延遲 `[1000, 2000, 4000]`（最多重試 3 次）；status 0 或 ≥ 500 用預設延遲；429 用 `retryAfterMs`（無則用預設延遲）並計入次數；401、400、413 不重試直接丟出。
- `editor/transcriptGap.ts`：Tiptap Node `TranscriptGap`，name `transcriptGap`，inline、atom，attrs `{ gapId: string; seq: number }`，渲染 `<span class="oc-gap" data-transcript-gap="{gapId}">⚠ 第 {seq} 段未轉寫・重試</span>`。
- `recording/transcriptInserter.ts`：`class TranscriptInserter { constructor(editor: Editor, anchorPos: number); insertText(text: string): void; insertGap(gapId: string, seq: number): void; get position(): number; destroy(): void }`；監聽 editor `transaction`，`docChanged` 時 `pos = tr.mapping.map(pos, 1)`。
- `recording/replaceGap.ts`：`replaceGap(editor: Editor, gapId: string, text: string): boolean`。
- `recording/pendingQueue.ts`：`createPendingQueue(db)` → `{ add(item: PendingSegment): Promise<void>; get(gapId): Promise<PendingSegment | undefined>; remove(gapId): Promise<void> }`，`PendingSegment = { gapId: string; noteId: string; seq: number; blob: Blob; mimeType: string; prompt: string }`。
- `recording/useRecorder.ts`：`useRecorder({ editor, noteId, settings, db })` → `{ state: 'idle' | 'needsSetup' | 'recording' | 'stopping'; error: string | null; notice: string | null; start(): Promise<void>; stop(): Promise<void>; retryGap(gapId: string): Promise<void> }`。
  - prompt：本次錄音已插入文字的最後 200 字。
  - 空字串結果：略過不插入（但仍推進順序）。
  - 401：停止錄音、`error = '存取金鑰錯誤，請重新設定'` 並開啟設定頁。
  - 麥克風被拒：`error = '無法使用麥克風，請在系統或瀏覽器設定中允許麥克風權限'`。
  - 重試仍失敗：存入 pendingQueue，插入 `transcriptGap`；點擊 gap 呼叫 `retryGap`，成功後 `replaceGap` 並移出佇列。
  - `visibilitychange` 回到前景且錄音已中斷：`notice = '錄音已中斷，已錄的部分會照常轉寫'`。

## 6. 相對 spec 的細化（已納入契約）

1. Android WebView 不支援 `window.print()`，因此手機版隱藏「匯出 PDF」（`Platform.canPrint = false`）。
2. CORS 預設來源改為實際值：`http://localhost:5173`（開發）、`https://localhost`（Capacitor Android）、`capacitor://localhost`（iOS）、`app://bundle`（Electron）。
3. 「重試」入口就是編輯器中的未轉寫標記本身（點擊即重送）。
4. 錄音中停用筆記切換、新增、刪除，避免文字插錯篇。
5. 停頓門檻：RMS < 0.01 持續 300ms。
6. `opencc-js@^1.4` 自帶型別（`package.json` 的 `exports["."].types` 指向 `./types/full.d.ts`，具名匯出 `Converter`），M3a 直接使用套件型別，不建立 `apps/api/src/types/opencc-js.d.ts`。`cn` → `tw` 只做字形轉換（例：「软件」→「軟件」，不會變成「軟體」）；台灣用詞轉換需 `twp`，目前不採用。
7. M3b 重試標記時若伺服器回 400 或 413（重送也會被同樣拒絕），`error = '伺服器無法轉寫這段錄音'`（`RECORDER_MESSAGES.retryRejected`），其他失敗仍是 `'重新轉寫失敗，請稍後再試'`。M4、M5 共用同一份訊息表。
8. M3b `withRetry` 對 429 的 `retryAfterMs` 上限為 300 秒（`MAX_RETRY_AFTER_MS`），與後端把上游 Retry-After 夾在 1–300 秒一致。
9. M3b 重試成功後 `replaceGap` 不進入復原歷史（`addToHistory: false`），音訊也不立即移出佇列：筆記是延遲存檔、且可能存檔失敗。NotesApp 載入筆記後呼叫 `pruneAudio(collectGapIds(notes))`，刪掉已無任何已存筆記引用的音訊（本次頁面錄的除外）；刪除筆記時 `forgetNote(noteId, stillReferenced)` 保留仍被其他筆記（貼上的標記）引用的音訊。`PendingQueue` 因此多了 `removeByNote(noteId, keep?)` 與 `removeUnreferenced(referenced)`。
