# M7 GitHub Actions CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 依追加設計 §2 建立 `.github/workflows/ci.yml`：推送到任何分支與 pull request 都會觸發；`web-api` job（ubuntu-latest、Node 24）依序跑 `npm ci` → `npm run typecheck` → `npm test` → `npm run build -w @oc/web` → `npx playwright install --with-deps chromium` → `npm run e2e` → `docker build -f apps/api/Dockerfile .`；`desktop` job（windows-latest、Node 24）跑 `npm ci` → 建置 web 與 desktop → Electron 端對端測試，不打包安裝檔。e2e 失敗時上傳 Playwright 報告，保留 7 天。

**Architecture:** 只有一個工作流程檔，兩個互相獨立的 job。`apps/web` 與 `apps/desktop` 目前不在每個分支上（`feat/api` 只有 `apps/api`、`packages/*`；`apps/desktop` 要到 M4 合併後才有），所以需要它們的步驟都用 `if: hashFiles('apps/<app>/package.json') != ''` 把關，缺少時改印一行 `::notice::` 說明略過。工作流程本身的結構由 `scripts/ci/workflow.test.mjs`（`node:test` + `yaml` 解析器）檢查，透過根 script `npm run test:workflow` 在本機與 CI 執行，讓拼錯的指令、順序或條件在推送前就被抓到。

**Tech Stack:** GitHub Actions（`actions/checkout@v5`、`actions/setup-node@v5`、`actions/upload-artifact@v4`）、Node 24 / npm 11、`node:test`、`yaml@^2.9.1`（eemeli/yaml，無相依套件）、Playwright 1.64、Docker（`node:24-slim`）。

## 設計決定

1. **缺少的 app 用 `hashFiles` 把關**：工作流程在每個分支都會跑。`feat/api` 上沒有 `apps/web`，`npm run build -w @oc/web` 會失敗（`npm error No workspaces found: --workspace=@oc/web`），`npx playwright install` 也找不到本地的 Playwright。因此 web 相關的三個步驟加上 `if: hashFiles('apps/web/package.json') != ''`；`desktop` job 的建置與 e2e 加上 `if: hashFiles('apps/desktop/package.json') != ''`（有 desktop 一定也有 web，因為 M4 的 desktop 直接讀 `apps/web/dist`）。缺少時各印一行 `::notice::`，在 GitHub 的執行摘要裡看得到略過了什麼。`hashFiles` 不能用在 job 層級的 `if`，所以 `desktop` job 本身照常啟動，只略過步驟。
2. **多一個 `npm run test:workflow` 步驟**：放在 `npm test` 之後。它只檢查工作流程檔，幾百毫秒就跑完，能防止之後的里程碑改壞 `ci.yml`。用 `node:test` 而不是 Vitest：根目錄沒有 Vitest 設定，`scripts/ci` 也不是 workspace；這樣根 `test` script 不必改，契約不動。`yaml` 是唯一新增的套件，只是 devDependency，不進 Docker 映像（Dockerfile 用 `--omit=dev`，而且只裝 `packages/shared` 與 `apps/api` 兩個 workspace）。
3. **Electron e2e 用 `npx playwright test`（`working-directory: apps/desktop`）**：M4 的 `npm run e2e -w @oc/desktop` 會再建置一次 web 和 desktop。設計把「建置」和「e2e」分成不同步驟，失敗時一眼就看得出是哪一段；所以建置用兩個獨立步驟，e2e 直接呼叫 Playwright。`npx` 會往上找到根 `node_modules/.bin/playwright`（已用 `npx --no-install tsc --version` 在 `apps/api` 驗證同樣的解析方式）。Electron 二進位由 `_electron` 直接啟動，不需要 `playwright install`。
4. **只在 e2e 本身失敗時上傳報告**：上傳步驟用 `if: failure() && steps.<id>.outcome == 'failure'`，避免 Docker 失敗時上傳一份通過的報告。web 上傳 `apps/web/playwright-report/` 與 `apps/web/test-results/`（web 設定有 html reporter 與 `trace: 'retain-on-failure'`）；desktop 的設定只有 `list` reporter，所以上傳 `apps/desktop/test-results/`。兩者都 `retention-days: 7`、`if-no-files-found: ignore`。
5. **Electron 下載**：`web-api` job 的 `env` 設 `ELECTRON_SKIP_BINARY_DOWNLOAD: '1'`；`desktop` job 與工作流程層級都不設，`npm ci` 才會下載 Electron。
6. **Actions 版本**：`actions/checkout@v5`、`actions/setup-node@v5`（以 Node 24 執行），`actions/upload-artifact@v4`（GitHub 會以 Node 24 執行舊版 action）。`setup-node` 用 `cache: npm`，快取鍵來自 `package-lock.json`。
7. **其他設定**：`permissions: contents: read`（不需要寫入權限）；`concurrency` 以 `github.ref` 分組並取消同一分支較舊的執行；每個 job `timeout-minutes: 30`。Docker 映像只建置不推送、不加標籤。
8. **不在 CI 執行**：真實語音測試（`npm run e2e:real -w @oc/web`，需要金鑰）與 Android 建置（需要 JDK 和 SDK）。結構測試會確認 `ci.yml` 沒有提到 `e2e:real`、`playwright.real`、`android`、`gradle`、`cap sync`、`secrets.`、`API_KEY`。

```js
// Structure checks for .github/workflows/ci.yml (add-ons design section 2).
// GitHub only reports a broken workflow after a push, so these checks catch
// typos, missing steps and wrong gates locally first.
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync } from 'node:fs';
import { parse } from 'yaml';

const repoRoot = new URL('../../', import.meta.url);
const workflowText = readFileSync(new URL('.github/workflows/ci.yml', repoRoot), 'utf8');
const workflow = parse(workflowText);
const rootScripts = JSON.parse(readFileSync(new URL('package.json', repoRoot), 'utf8')).scripts;

// apps/web and apps/desktop live on other branches until they are merged,
// so every step that needs one of them only runs when its package.json exists.
const WEB_GATE = "hashFiles('apps/web/package.json') != ''";

function job(name) {
  const found = workflow.jobs?.[name];
  assert.ok(found, `job "${name}" is missing`);
  return found;
}

function isNotice(step) {
  return typeof step.run === 'string' && step.run.trim().startsWith('echo "::notice::');
}

/** The run commands of a job, in order, without the skip notices. */
function commands(jobDef) {
  return jobDef.steps.filter((s) => typeof s.run === 'string' && !isNotice(s)).map((s) => s.run.trim());
}

function stepByRun(jobDef, command) {
  const found = jobDef.steps.find((s) => typeof s.run === 'string' && s.run.trim() === command);
  assert.ok(found, `step "${command}" is missing`);
  return found;
}

function usesIndex(jobDef, action) {
  return jobDef.steps.findIndex((s) => typeof s.uses === 'string' && s.uses.startsWith(`${action}@`));
}

function assertNodeSetup(jobDef) {
  const checkout = usesIndex(jobDef, 'actions/checkout');
  const setup = usesIndex(jobDef, 'actions/setup-node');
  assert.ok(checkout >= 0, 'actions/checkout is missing');
  assert.ok(setup > checkout, 'actions/setup-node must come after actions/checkout');
  const install = jobDef.steps.findIndex((s) => s.run?.trim() === 'npm ci');
  assert.ok(install > setup, 'npm ci must come after actions/setup-node');
  const { with: options } = jobDef.steps[setup];
  assert.equal(String(options['node-version']), '24');
  assert.equal(options.cache, 'npm');
}

test('runs on a push to any branch and on pull requests', () => {
  assert.deepEqual(workflow.on.push, { branches: ['**'] });
  assert.ok('pull_request' in workflow.on, 'pull_request trigger is missing');
});

test('web-api runs on ubuntu with Node 24, the npm cache and no Electron download', () => {
  const webApi = job('web-api');
  assert.equal(webApi['runs-on'], 'ubuntu-latest');
  assertNodeSetup(webApi);
  assert.equal(webApi.env?.ELECTRON_SKIP_BINARY_DOWNLOAD, '1');
});

test('web-api runs the CI commands in order', () => {
  assert.deepEqual(commands(job('web-api')), [
    'npm ci',
    'npm run typecheck',
    'npm test',
    'npm run test:workflow',
    'npm run build -w @oc/web',
    'npx playwright install --with-deps chromium',
    'npm run e2e',
    'docker build -f apps/api/Dockerfile .',
  ]);
});

test('web-api only runs the web steps when apps/web exists', () => {
  const webApi = job('web-api');
  const webCommands = ['npm run build -w @oc/web', 'npx playwright install --with-deps chromium', 'npm run e2e'];
  for (const command of commands(webApi)) {
    const expected = webCommands.includes(command) ? WEB_GATE : undefined;
    assert.equal(stepByRun(webApi, command).if, expected, `wrong condition on "${command}"`);
  }
  const notice = webApi.steps.find(isNotice);
  assert.ok(notice, 'skip notice for apps/web is missing');
  assert.equal(notice.if, "hashFiles('apps/web/package.json') == ''");
});

test('web-api uploads the Playwright report for 7 days when the web e2e fails', () => {
  const webApi = job('web-api');
  assert.equal(stepByRun(webApi, 'npm run e2e').id, 'web-e2e');
  const upload = webApi.steps[usesIndex(webApi, 'actions/upload-artifact')];
  assert.ok(upload, 'actions/upload-artifact is missing');
  assert.equal(upload.if, "failure() && steps.web-e2e.outcome == 'failure'");
  assert.match(upload.with.path, /apps\/web\/playwright-report\//);
  assert.equal(upload.with['retention-days'], 7);
});

test('every root npm script the workflow runs exists', () => {
  for (const jobDef of Object.values(workflow.jobs)) {
    for (const command of commands(jobDef)) {
      const match = /^npm run ([\w:-]+)$/.exec(command);
      if (match) assert.ok(rootScripts[match[1]], `root script "${match[1]}" is missing`);
    }
  }
});

test('never runs the real voice test, Android builds or anything that needs secrets', () => {
  for (const banned of ['e2e:real', 'playwright.real', 'android', 'gradle', 'cap sync', 'secrets.', 'API_KEY']) {
    assert.ok(!workflowText.includes(banned), `ci.yml must not mention "${banned}"`);
  }
});
```

`.github/workflows/ci.yml`：

```yaml
# CI for open-copilot (add-ons design section 2).
# apps/web and apps/desktop may be missing on a branch until it is merged,
# so their steps are gated on their package.json and leave a notice when skipped.
name: CI

on:
  push:
    branches: ['**']
  pull_request:

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  web-api:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    env:
      # The Electron binary is only needed by the desktop job.
      ELECTRON_SKIP_BINARY_DOWNLOAD: '1'
    steps:
      - name: Check out
        uses: actions/checkout@v5

      - name: Set up Node 24
        uses: actions/setup-node@v5
        with:
          node-version: '24'
          cache: npm

      - name: Install dependencies
        run: npm ci

      - name: Typecheck
        run: npm run typecheck

      - name: Unit tests
        run: npm test

      - name: Check the CI workflow
        run: npm run test:workflow

      - name: Note skipped web steps
        if: hashFiles('apps/web/package.json') == ''
        run: echo "::notice::apps/web is not on this branch; web build and e2e skipped"

      - name: Build web
        if: hashFiles('apps/web/package.json') != ''
        run: npm run build -w @oc/web

      - name: Install Playwright Chromium
        if: hashFiles('apps/web/package.json') != ''
        run: npx playwright install --with-deps chromium

      - name: Web e2e
        id: web-e2e
        if: hashFiles('apps/web/package.json') != ''
        run: npm run e2e

      - name: Build API Docker image
        run: docker build -f apps/api/Dockerfile .

      - name: Upload Playwright report
        if: failure() && steps.web-e2e.outcome == 'failure'
        uses: actions/upload-artifact@v4
        with:
          name: playwright-report-web
          path: |
            apps/web/playwright-report/
            apps/web/test-results/
          retention-days: 7
          if-no-files-found: ignore
```
