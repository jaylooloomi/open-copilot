# M8 筆記備份匯出／匯入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 依追加設計 §3，讓使用者把所有筆記備份成 `open-copilot-backup-YYYYMMDD-HHmm.json`（`{ "app": "open-copilot", "version": 1, "exportedAt": <epoch ms>, "notes": Note[] }`，不含音訊），再從這個檔案匯入：先驗證格式，不合法就顯示「這不是 open-copilot 的備份檔」且不寫入任何資料；合法時以 `id` 合併，保留 `updatedAt` 較新的版本，完成後顯示「已匯入 N 篇，略過 M 篇（本機版本較新）」。NoteList 底部有「備份」「匯入」兩個按鈕，錄音中停用。有筆記且超過 7 天沒有備份（或從未備份）時，Banner 改成「已超過 7 天沒有備份筆記」加「立即備份」按鈕，備份成功後恢復原本的 Banner。

**Architecture:** 新增 `packages/core/src/backup/`：`backupFormat.ts`（檔名、序列化、以編輯器 schema 驗證）、`mergeNotes.ts`（純函式合併）、`backupReminder.ts`（`oc.lastBackupAt` 讀寫與「該備份了嗎」判斷）、`useBackup.ts`（把以上接到 `platform.fileSaver` 與 `useNotes`）。`useNotes` 新增 `importNotes(incoming)`：先寫出待存的編輯，再寫入要新增／取代的筆記，最後重新合併進記憶體清單。`useNoteEditor` 新增選填的 `revision`，讓匯入取代目前開啟的筆記時能重建編輯器。UI 是新元件 `components/BackupControls.tsx`（經 `NoteList` 新的 `footer` 插槽放在清單底部）與 `Banner` 的提醒狀態；`NotesApp` 負責串接。

**Tech Stack:** React 19、TypeScript 5.9、Tiptap 3（`getSchema` + ProseMirror `Node.check()` 驗證內容）、Vitest 3 + Testing Library + jsdom、Playwright 1.64（web e2e）。

## 設計決定

1. **內容用編輯器 schema 驗證**：設計要求驗證每篇 `Note` 的欄位型別。`content` 只檢查「是物件」不夠：Tiptap 遇到未知節點不會丟錯，而是在 console 警告後換成空白文件，使用者一編輯就把匯入的內容蓋掉。因此 `content` 必須是 `type: 'doc'`，並以 `getSchema(createExtensions())` 的 `nodeFromJSON(content).check()` 驗證（與 `export/toHtml.ts` 相同的快取寫法）。另外 `id` 必須是非空字串、檔案內不得重複，`createdAt`／`updatedAt`／`exportedAt` 必須是有限數字。檔案開頭的 BOM 會先去掉（Windows 記事本存檔常見）。驗證通過後只保留 `Note` 的五個欄位，其他欄位丟掉。
2. **合併規則**：`mergeNotes(local, incoming)` 是純函式。本機沒有的 `id` 直接新增；本機也有時，只有匯入版本的 `updatedAt` **嚴格較新**才取代，相同或較舊都算「略過」（訊息固定寫「本機版本較新」，相同時間的情況也歸在這裡，內容視為相同）。`imported` = 新增 + 取代的篇數。
3. **`useNotes.importNotes`**：先 `flushSaves()`，讓待存的編輯先送進 IndexedDB，之後的匯入寫入才排在它後面。依序 `storage.put` 要寫入的筆記；某一篇失敗就停止，已寫入的那些仍併入清單，然後把錯誤丟出（`useBackup` 顯示「匯入失敗，請再試一次。」）。寫完後再用 `mergeNotes(notesRef.current, stored)` 合併一次：寫入期間使用者若又編輯了同一篇，那份編輯較新，會保留下來，並由原本的自動儲存覆寫回去。目前開啟的筆記保持不變；回傳的 `replacedActive` 表示它被匯入版本取代了。
4. **取代開啟中的筆記時重建編輯器**：`useNoteEditor` 只在 `noteId` 改變時重建，同一篇筆記的新內容會被忽略。新增選填的 `revision`（預設 0）加入 `useEditor` 的 deps；`NotesApp` 在 `replacedActive` 時把它加一。
5. **提醒的「有筆記」不含空白筆記**：第一次開啟 app 時 `useNotes` 會自動建立一篇空白筆記。若把它算成「有筆記」，新使用者一打開就會看到「已超過 7 天沒有備份筆記」，原本的錄製提示永遠不會出現（現有測試與 e2e 也依賴這個提示）。因此 `isBackupDue` 只在至少有一篇**非空白**筆記時才提醒：標題去空白後非空，或內文有非空白文字，或有段落／文字／換行以外的節點（標題、清單、⚠ 未轉寫標記等）。「超過 7 天」是嚴格大於 `7 × 24 × 60 × 60 × 1000` 毫秒；從未備份過且有非空白筆記時一律提醒（文案依設計固定為「已超過 7 天沒有備份筆記」）。
6. **`oc.lastBackupAt`**：以字串存 epoch 毫秒，`fileSaver.save` 成功 resolve 後才寫入。讀不到、不是正有限數字、或 localStorage 丟錯（隱私模式）都當作從未備份。網頁版的 `save` 只是觸發下載，無法得知使用者是否真的存了檔；這與其他平台的契約一致（`save` resolve 即視為成功）。依 M2 起的既有慣例（`NoteActions.tsx` 與 desktop 的 `desktopFileSaver.ts`），使用者取消存檔對話框（Electron）或分享選單（Android）時，`FileSaver.save` 會以 `name === 'AbortError'` 的錯誤 reject；取消不算失敗：不顯示「備份失敗，請再試一次。」、不記錄錯誤、不寫 `oc.lastBackupAt`、不顯示成功訊息，提醒維持原狀。判斷用的 `isAbortError` 從 `NoteActions.tsx` 移到共用的 `platform/isAbortError.ts`，兩邊共用。
7. **訊息呈現**：成功訊息（「已備份 N 篇筆記」「已匯入 N 篇，略過 M 篇（本機版本較新）」）以 `role="status"` 顯示在備份按鈕下方，**只在有訊息時才渲染**，因為既有 e2e 以 `page.getByRole('status')` 讀取 `NoteActions` 唯一的狀態列。錯誤（不是備份檔、讀檔失敗、寫入失敗、儲存檔案失敗）走既有的 `StorageAlert`（`setStorageError`），它在 `<main>` 外面，抽屜開著時也看得到。
8. **檔案選擇**：`<input type="file" accept="application/json,.json" hidden aria-label="選擇備份檔">`，由「匯入」按鈕呼叫 `click()` 開啟；選完立刻把 `value` 清空，同一個檔案可以再選一次。jsdom 的 `Blob` 沒有 `text()`，所以讀檔用 `FileReader`（`readFileText`）。
9. **按鈕停用**：錄音中（`recording`）或備份／匯入進行中（`busy`）時，「備份」「匯入」「立即備份」都停用；`useBackup` 另以 ref 擋掉進行中重複觸發。備份／匯入進行中時筆記清單（選取、新增、刪除）也一併停用（`NoteList` 的 `disabled={recording || backup.busy}`）：否則匯入還在等 `storage.put(X)` 時刪除 X，IndexedDB 會先寫入再刪除，而 `importNotes` 最後的 `mergeNotes` 又會把 X 加回記憶體清單，畫面與儲存不一致。
10. **清單底部固定可見**：`.oc-sidebar` 是捲動容器（`overflow-y: auto`），`.oc-notelist-footer` 以 `position: sticky; bottom: 0` 加上 `var(--oc-surface)` 底色固定在側欄底部，筆記很多時「備份」「匯入」仍看得到（桌面與手機抽屜相同）。
11. **不含音訊**：備份只有筆記 JSON。匯入到另一台裝置的 ⚠ 未轉寫標記沒有對應音訊，這是設計明定的取捨，本里程碑不處理。

建立 `packages/core/src/backup/backupFormat.ts`：

```ts
import type { JSONContent, Note } from '@oc/shared';
import { getSchema } from '@tiptap/react';
import { createExtensions } from '../editor/extensions';

export const BACKUP_APP = 'open-copilot';
export const BACKUP_VERSION = 1;
export const BACKUP_MIME = 'application/json';

/** The whole backup file: every note, without any recorded audio. */
export interface BackupFile {
  app: typeof BACKUP_APP;
  version: typeof BACKUP_VERSION;
  /** Epoch ms. */
  exportedAt: number;
  notes: Note[];
}

/** Thrown by parseBackup for anything that is not a valid open-copilot backup. */
export class InvalidBackupError extends Error {
  constructor(reason: string) {
    super(`Invalid backup: ${reason}`);
    this.name = 'InvalidBackupError';
  }
}

type Schema = ReturnType<typeof getSchema>;

let cachedSchema: Schema | undefined;

/** The editor's schema, built once on first use. */
function editorSchema(): Schema {
  cachedSchema ??= getSchema(createExtensions());
  return cachedSchema;
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

function isTimestamp(value: unknown): value is number {
  return typeof value === 'number' && Number.isFinite(value);
}

/**
 * A document the editor can open as is. Tiptap does not reject unknown nodes: it swaps in an
 * empty document, and the next edit would overwrite the imported note with it.
 */
function isEditorDoc(value: unknown): value is JSONContent {
  if (!isRecord(value) || value.type !== 'doc') return false;
  try {
    editorSchema().nodeFromJSON(value).check();
    return true;
  } catch {
    return false;
  }
}

function isNote(value: unknown): value is Note {
  return (
    isRecord(value) &&
    typeof value.id === 'string' &&
    value.id.trim() !== '' &&
    typeof value.title === 'string' &&
    isTimestamp(value.createdAt) &&
    isTimestamp(value.updatedAt) &&
    isEditorDoc(value.content)
  );
}

/** Only the Note fields, so nothing else is written to storage or to the file. */
function pickNoteFields({ id, title, content, createdAt, updatedAt }: Note): Note {
  return { id, title, content, createdAt, updatedAt };
}

export function createBackup(notes: readonly Note[], exportedAt: number): BackupFile {
  return { app: BACKUP_APP, version: BACKUP_VERSION, exportedAt, notes: notes.map(pickNoteFields) };
}

export function serializeBackup(backup: BackupFile): string {
  return `${JSON.stringify(backup, null, 2)}\n`;
}

const pad = (value: number, width = 2) => String(value).padStart(width, '0');

/** `open-copilot-backup-YYYYMMDD-HHmm.json`, in local time. */
export function backupFilename(date: Date): string {
  const day = `${pad(date.getFullYear(), 4)}${pad(date.getMonth() + 1)}${pad(date.getDate())}`;
  const time = `${pad(date.getHours())}${pad(date.getMinutes())}`;
  return `open-copilot-backup-${day}-${time}.json`;
}

/** Parses and validates a backup file's text; throws InvalidBackupError for anything else. */
export function parseBackup(text: string): BackupFile {
  let data: unknown;
  try {
    // Windows editors often save JSON with a byte order mark, which JSON.parse rejects.
    data = JSON.parse(text.replace(/^\uFEFF/, ''));
  } catch {
    throw new InvalidBackupError('not JSON');
  }
  if (!isRecord(data)) throw new InvalidBackupError('not an object');
  if (data.app !== BACKUP_APP) throw new InvalidBackupError('not an open-copilot backup');
  if (data.version !== BACKUP_VERSION) throw new InvalidBackupError('unsupported version');
  if (!isTimestamp(data.exportedAt)) throw new InvalidBackupError('exportedAt is not a number');
  if (!Array.isArray(data.notes)) throw new InvalidBackupError('notes is not an array');

  const ids = new Set<string>();
  const notes = data.notes.map((value: unknown, index: number) => {
    if (!isNote(value)) throw new InvalidBackupError(`note ${index} is malformed`);
    if (ids.has(value.id)) throw new InvalidBackupError(`note id ${value.id} appears twice`);
    ids.add(value.id);
    return pickNoteFields(value);
  });
  return { app: BACKUP_APP, version: BACKUP_VERSION, exportedAt: data.exportedAt, notes };
}
```

```ts
import type { Note } from '@oc/shared';
import { sortByUpdatedDesc } from '../notes/noteStore';

export interface MergeResult {
  /** Local and imported notes together, newest `updatedAt` first. */
  notes: Note[];
  /** Imported notes that were added or replaced a local one, in import order; store these. */
  toWrite: Note[];
  /** Notes added or replaced (`toWrite.length`). */
  imported: number;
  /** Imported notes whose local copy is as new or newer; the local copy is kept. */
  skipped: number;
}

/**
 * Merges imported notes into the local ones by `id`: an unknown id is added, and a known one is
 * replaced only when the imported `updatedAt` is strictly newer.
 */
export function mergeNotes(local: readonly Note[], incoming: readonly Note[]): MergeResult {
  const byId = new Map(local.map((note) => [note.id, note]));
  const toWrite: Note[] = [];
  let skipped = 0;
  for (const note of incoming) {
    const existing = byId.get(note.id);
    if (existing && existing.updatedAt >= note.updatedAt) {
      skipped += 1;
      continue;
    }
    byId.set(note.id, note);
    toWrite.push(note);
  }
  return { notes: sortByUpdatedDesc([...byId.values()]), toWrite, imported: toWrite.length, skipped };
}
```

```ts
import type { JSONContent, Note } from '@oc/shared';

/** localStorage key holding the epoch ms of the last successful backup. */
export const LAST_BACKUP_KEY = 'oc.lastBackupAt';

/** Remind once the last backup is more than this old. */
export const BACKUP_REMINDER_MS = 7 * 24 * 60 * 60 * 1000;

/** Nodes that hold nothing by themselves; any other node (heading, list, ⚠ marker) is content. */
const EMPTY_NODE_TYPES = new Set(['doc', 'paragraph', 'text', 'hardBreak']);

function isBlankNode(node: JSONContent): boolean {
  if (node.type !== undefined && !EMPTY_NODE_TYPES.has(node.type)) return false;
  if (typeof node.text === 'string' && node.text.trim() !== '') return false;
  return (node.content ?? []).every(isBlankNode);
}

/** No title and no body, like the note the app creates on first start. */
export function isBlankNote(note: Note): boolean {
  return note.title.trim() === '' && isBlankNode(note.content);
}

/**
 * True when some note has content and the last backup is more than 7 days old, or there has
 * never been one. Blank notes alone never remind.
 */
export function isBackupDue(notes: readonly Note[], lastBackupAt: number | undefined, now: number): boolean {
  if (notes.every((note) => isBlankNote(note))) return false;
  return lastBackupAt === undefined || now - lastBackupAt > BACKUP_REMINDER_MS;
}

/** The last backup time, or undefined when there is none or it cannot be read. */
export function loadLastBackupAt(): number | undefined {
  try {
    const raw = localStorage.getItem(LAST_BACKUP_KEY);
    if (raw === null) return undefined;
    const value = Number(raw);
    return Number.isFinite(value) && value > 0 ? value : undefined;
  } catch {
    return undefined;
  }
}

/** Records a successful backup; a storage failure is logged, never thrown. */
export function saveLastBackupAt(at: number): void {
  try {
    localStorage.setItem(LAST_BACKUP_KEY, String(at));
  } catch (error) {
    console.error('Failed to save the last backup time', error);
  }
}
```

```ts
 * component stays mounted; inside `<Activity mode="hidden">` or a hidden Suspense subtree
 * Tiptap may destroy it, so this hook is not meant for those.
 */
export function useNoteEditor({ noteId, revision = 0, content, onChange }: UseNoteEditorOptions): TiptapEditor {
  const extensions = useMemo(() => createExtensions(), []);
  // The note each editor instance was created for. useEditor only replaces the editor in a
  // passive effect after a noteId change, while it already routes onUpdate to the newest
  // options, so for a moment the old note's editor would report into the new note's onChange.
  const [owners] = useState(() => new WeakMap<TiptapEditor, string | undefined>());
  return useEditor(
    {
      immediatelyRender: true,
      extensions,
      content,
      editorProps: {
        attributes: {
          role: 'textbox',
          'aria-multiline': 'true',
          'aria-label': '筆記內文',
          class: 'oc-prose',
        },
      },
      // Runs synchronously in the Editor constructor with the options of the render that
      // created it, so it tags the instance with that render's noteId.
      onBeforeCreate: ({ editor }) => {
        owners.set(editor, noteId);
      },
      // useEditor always calls the latest onUpdate; drop updates from an editor that belongs
      // to a note other than the current one.
      onUpdate: ({ editor, transaction, appendedTransactions }) => {
        if (!transaction.docChanged) {
          // Only plugins (appendTransaction) changed the doc. Not an edit when all they did was
          // StarterKit's TrailingNode appending an empty paragraph to a note that ends in a list,
          // heading or quote, which happens on any transaction, even a click that only moves the
          // selection; that paragraph is saved with the next real edit. Any other plugin edit
          // is reported.
          if (!appendedTransactions.some((tr) => tr.docChanged)) return;
          if (onlyAddsEmptyParagraph(transaction.doc, editor.state.doc)) return;
        }
        // No note, no owner to report to.
        const owner = owners.get(editor);
        if (noteId !== undefined && owner === noteId) onChange(editor.getJSON(), owner);
      },
    },
    [noteId, revision],
  );
}
```

```ts
import type { Note } from '@oc/shared';
import { useRef, useState } from 'react';
import type { ImportNotesResult } from '../notes/useNotes';
import { isAbortError } from '../platform/isAbortError';
import type { FileSaver } from '../platform/types';
import { BACKUP_MIME, backupFilename, createBackup, parseBackup, serializeBackup } from './backupFormat';
import { isBackupDue, loadLastBackupAt, saveLastBackupAt } from './backupReminder';

export const NOT_A_BACKUP_MESSAGE = '這不是 open-copilot 的備份檔';
export const BACKUP_FAILED_MESSAGE = '備份失敗，請再試一次。';
export const IMPORT_FAILED_MESSAGE = '匯入失敗，請再試一次。';
export const READ_FAILED_MESSAGE = '無法讀取檔案，請再試一次。';

export interface UseBackupOptions {
  /** The notes to back up, as shown (unsaved edits included). */
  notes: readonly Note[];
  fileSaver: FileSaver;
  /** Merges and stores the notes of a backup (useNotes.importNotes). */
  importNotes(incoming: readonly Note[]): Promise<ImportNotesResult>;
  /** Tells the user about a failure (`message`) and logs it (`error`). */
  onError(message: string, error: unknown): void;
  /** Clock for the backup time and the reminder; injectable for tests. */
  now?: () => number;
}

export interface UseBackupResult {
  /** Show the backup reminder instead of the usual banner. */
  backupDue: boolean;
  /** A backup or import is running; starting another one is ignored. */
  busy: boolean;
  /** Result of the last successful backup or import. */
  message: string | undefined;
  /** Saves every note as `open-copilot-backup-YYYYMMDD-HHmm.json`. Never rejects. */
  backup(): Promise<void>;
  /** Validates a chosen backup file and imports its notes. Never rejects. */
  importFile(file: Blob): Promise<void>;
}

/** Reads a file as UTF-8 text through FileReader (jsdom's Blob has no text()). */
export function readFileText(file: Blob): Promise<string> {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result as string);
    reader.onerror = () => reject(reader.error);
    reader.readAsText(file);
  });
}

export function useBackup({
  notes,
  fileSaver,
  importNotes,
  onError,
  now = Date.now,
}: UseBackupOptions): UseBackupResult {
  const [lastBackupAt, setLastBackupAt] = useState(loadLastBackupAt);
  const [busy, setBusy] = useState(false);
  const [message, setMessage] = useState<string | undefined>(undefined);
  // State updates land after the next render; the ref stops a second click right away.
  const busyRef = useRef(false);

  const run = async (task: () => Promise<void>) => {
    if (busyRef.current) return;
    busyRef.current = true;
    setBusy(true);
    setMessage(undefined);
    try {
      await task();
    } finally {
      busyRef.current = false;
      setBusy(false);
    }
  };

  const backup = () =>
    run(async () => {
      const at = now();
      const data = new Blob([serializeBackup(createBackup(notes, at))], { type: BACKUP_MIME });
      try {
        await fileSaver.save(backupFilename(new Date(at)), data);
      } catch (error) {
        // The user cancelled the save dialog: not a failure and not a backup.
        if (!isAbortError(error)) onError(BACKUP_FAILED_MESSAGE, error);
        return;
      }
      saveLastBackupAt(at);
      setLastBackupAt(at);
      setMessage(`已備份 ${notes.length} 篇筆記`);
    });

  const importFile = (file: Blob) =>
    run(async () => {
      let text: string;
      try {
        text = await readFileText(file);
      } catch (error) {
        onError(READ_FAILED_MESSAGE, error);
        return;
      }
      let incoming: Note[];
      try {
        incoming = parseBackup(text).notes;
      } catch (error) {
        onError(NOT_A_BACKUP_MESSAGE, error);
        return;
      }
      try {
        const { imported, skipped } = await importNotes(incoming);
        setMessage(`已匯入 ${imported} 篇，略過 ${skipped} 篇（本機版本較新）`);
      } catch (error) {
        onError(IMPORT_FAILED_MESSAGE, error);
      }
    });

  return { backupDue: isBackupDue(notes, lastBackupAt, now()), busy, message, backup, importFile };
}
```

```tsx
function getRecorderDb(): ReturnType<typeof openAppDb> {
  if (sharedRecorderDb) return sharedRecorderDb;
  const db = openAppDb();
  sharedRecorderDb = db;
  db.catch((error: unknown) => {
    // Failures surface where the queue is used; this only keeps them from being "unhandled".
    console.error('Failed to open the recording queue', error);
    // The next mount tries again.
    if (sharedRecorderDb === db) sharedRecorderDb = null;
  });
  return db;
}

  }

  const closeDrawer = () => setDrawerOpen(false);
  const recording = recorder.state === 'recording' || recorder.state === 'stopping';
  const backupDisabled = recording || backup.busy;

  // A failed create rejects without adding the note; deleteNote rejects only when the remove
  // failed, after putting the note back. Either way the user has to be told, and the rejection
  // must not go unhandled.
  const reportFailure = (message: string, logMessage: string) => (error: unknown) => {
    console.error(logMessage, error);
    setStorageError(message);
  };

  // backup() and importFile() report their own failures and never reject.
  const startBackup = () => {
    setStorageError(undefined);
    void backup.backup();
  };

  const startImport = (file: File) => {
    setStorageError(undefined);
    void backup.importFile(file);
  };

  const confirmDelete = (id: string) => {
    const target = notes.find((n) => n.id === id);
    if (!target) return;
    if (window.confirm(`確定要刪除「${displayTitle(target)}」嗎？此動作無法復原。`)) {
      setStorageError(undefined);
      // Once the note is gone its ⚠ markers can never be retried, so drop their audio as well
      // (only after the note itself was deleted; a failed delete keeps both), except for markers
      // that were copied into another note. forgetNote never rejects.
      const stillReferenced = collectGapIds(notes.filter((n) => n.id !== id));
      deleteNote(id).then(
        () => recorder.forgetNote(id, stillReferenced),
        reportFailure('刪除筆記失敗，請再試一次。', 'Failed to delete note'),
      );
    }
  };

  const onRecord = () => {
    if (recorder.state === 'needsSetup') setSettingsOpen(true);
    else if (recorder.state === 'idle') void recorder.start();
    else if (recorder.state === 'recording') void recorder.stop();
  };

  const retryGap = (gapId: string) => {
    if (recorder.state === 'needsSetup') setSettingsOpen(true);
    else void recorder.retryGap(gapId);
  };

  // The ⚠ 第 N 段未轉寫・重試 marker is the retry button.
  const onDocumentClick = (event: MouseEvent<HTMLDivElement>) => {
    const gap = event.target instanceof Element ? event.target.closest('[data-transcript-gap]') : null;
    const gapId = gap?.getAttribute('data-transcript-gap');
    if (!gapId) return;
    event.preventDefault();
    retryGap(gapId);
  };

  // Keyboard users select the marker (arrow keys select it as a whole) and press Enter or Space.
  // Capture phase, so ProseMirror does not first replace the selected marker with a line break.
  const onDocumentKeyDownCapture = (event: KeyboardEvent<HTMLDivElement>) => {
    if (event.key !== 'Enter' && event.key !== ' ') return;
    if (event.shiftKey || event.ctrlKey || event.altKey || event.metaKey) return;
    if (event.nativeEvent.isComposing) return;
    if (!(event.target instanceof Node) || !editor.view.dom.contains(event.target)) return;
    const { selection } = editor.state;
    if (!(selection instanceof NodeSelection) || selection.node.type.name !== TRANSCRIPT_GAP_TYPE) {
      return;
    }
    const gapId = String(selection.node.attrs.gapId ?? '');
    if (!gapId) return;
    event.preventDefault();
    event.stopPropagation();
    retryGap(gapId);
  };

  return (
    <div className="oc-app" data-drawer-open={drawerOpen ? 'true' : 'false'}>
      <aside className="oc-sidebar" id="oc-sidebar" ref={sidebarRef}>
        <NoteList
          notes={notes}
          activeId={activeNote.id}
          // Also while a backup or import runs: deleting a note that importNotes is still writing
          // would let the final merge put it back in the list.
          disabled={recording || backup.busy}
          onSelect={(id) => {
            selectNote(id);
            closeDrawer();
          }}
          onCreate={() => {
            setStorageError(undefined);
            createNote().then(
              (created) => setFocusTitleOf(created.id),
              reportFailure('新增筆記失敗，請再試一次。', 'Failed to create note'),
            );
            closeDrawer();
          }}
          onDelete={confirmDelete}
          footer={
            <BackupControls
              disabled={backupDisabled}
              message={backup.message}
              onBackup={startBackup}
              onImportFile={startImport}
            />
          }
        />
        {drawerOpen && (
          // <main> is inert while the drawer is open, so the menu button cannot close it. Touch
          // screen reader users reach this one; keyboard users press Escape.
          <button
            type="button"
            className="oc-visually-hidden"
            tabIndex={-1}
            onClick={closeDrawer}
          >
            關閉筆記清單
          </button>
        )}
      </aside>
      {drawerOpen && <div className="oc-backdrop" aria-hidden="true" onClick={closeDrawer} />}

      <main className="oc-main" inert={drawerOpen}>
        <header className="oc-topbar">
          <button
            ref={menuButtonRef}
            type="button"
            className="oc-menu-btn"
            aria-label={drawerOpen ? '關閉筆記清單' : '開啟筆記清單'}
            aria-controls="oc-sidebar"
            aria-expanded={drawerOpen}
            onClick={() => setDrawerOpen((open) => !open)}
          >
            <Menu size={20} />
          </button>
          <ActionBar
            recordState={recorder.state}
            onRecord={onRecord}
            onOpenSettings={() => setSettingsOpen(true)}
          />
        </header>
        <Banner backupDue={backup.backupDue} backupDisabled={backupDisabled} onBackup={startBackup} />
        {(recorder.error || recorder.notice) && (
          <div className="oc-recorder-alert" role="alert">
            <div className="oc-recorder-alert-text">
              {recorder.error && <p className="oc-recorder-error">{recorder.error}</p>}
              {recorder.notice && <p className="oc-recorder-notice">{recorder.notice}</p>}
            </div>
            <button
              type="button"
              className="oc-alert-close"
              aria-label="關閉訊息"
              onClick={recorder.dismissMessages}
            >
              <X size={16} aria-hidden="true" />
            </button>
          </div>
        )}
        <Toolbar editor={editor} note={activeNote} />
        <div
          className="oc-document"
          onClick={onDocumentClick}
          onKeyDownCapture={onDocumentKeyDownCapture}
        >
          <TitleInput
            inputRef={titleRef}
            value={activeNote.title}
            onChange={(title) => updateNote(activeNote.id, { title })}
            onEnter={() => {
              // Set the cursor and move DOM focus synchronously. commands.focus() focuses a frame
              // later, so a key typed right after Enter would land in the title, and the late
              // focus could reset a selection made meanwhile (e.g. ArrowRight onto a ⚠ marker).
              const { state, view } = editor;
              view.dispatch(state.tr.setSelection(Selection.atStart(state.doc)).scrollIntoView());
              view.focus();
            }}
          />
          <Editor editor={editor} />
        </div>
      </main>

      {settingsOpen && (
        <SettingsDialog
          settings={settings}
          onSave={(next) => {
            saveSettings(next);
            setSettingsOpen(false);
          }}
          onClose={() => setSettingsOpen(false)}
        />
      )}

      {storageError ? (
        <StorageAlert message={storageError} onDismiss={() => setStorageError(undefined)} />
      ) : (
        saveFailed && (
          <StorageAlert
            message="筆記儲存失敗，變更尚未存檔。繼續編輯時會再試一次。"
            onDismiss={dismissSaveError}
          />
        )
      )}
    </div>
  );
}
```

```ts
import { readFile } from 'node:fs/promises';
import { expect, test, type FileChooser, type Page } from '@playwright/test';

interface StoredNote {
  id: string;
  title: string;
  content: unknown;
  createdAt: number;
  updatedAt: number;
}

/** Reads what the app has persisted in IndexedDB (database "open-copilot", store "notes"). */
function savedNotes(page: Page): Promise<StoredNote[]> {
  return page.evaluate(
    () =>
      new Promise<StoredNote[]>((resolve, reject) => {
        const open = indexedDB.open('open-copilot');
        open.onerror = () => reject(open.error);
        open.onsuccess = () => {
          const db = open.result;
          const request = db.transaction('notes', 'readonly').objectStore('notes').getAll();
          request.onerror = () => reject(request.error);
          request.onsuccess = () => {
            db.close();
            resolve(request.result as StoredNote[]);
          };
        };
      }),
  );
}

/** Opens the file picker from 匯入 and chooses `files`. */
async function importFrom(page: Page, files: Parameters<FileChooser['setFiles']>[0]) {
  const chooser = page.waitForEvent('filechooser');
  await page.getByRole('button', { name: '匯入', exact: true }).click();
  await (await chooser).setFiles(files);
}

test('備份 → 清空資料 → 匯入，筆記內容一致', async ({ page, browser }) => {
  // A fresh start only has the empty first note: the usual tip, not the reminder.
  await expect(page.getByRole('note')).toContainText('手動輸入累了？');

  await page.getByRole('textbox', { name: '標題' }).fill('週會紀錄');
  await page.getByRole('textbox', { name: '筆記內文' }).click();
  await page.keyboard.type('第一點');
  await page.keyboard.press('Enter');
  await page.keyboard.press('Control+B');
  await page.keyboard.type('重要');

  // Never backed up, and there is a note: the banner reminds.
  await expect(page.getByRole('note')).toContainText('已超過 7 天沒有備份筆記');
  // Wait for the debounced autosave, so the stored note is what the backup holds.
  await expect.poll(async () => JSON.stringify(await savedNotes(page))).toContain('重要');
  const before = await savedNotes(page);
  expect(before).toHaveLength(1);

  const downloaded = page.waitForEvent('download');
  await page.getByRole('button', { name: '備份', exact: true }).click();
  const download = await downloaded;
  expect(download.suggestedFilename()).toMatch(/^open-copilot-backup-\d{8}-\d{4}\.json$/);
  const backupPath = await download.path();
  const backup = JSON.parse(await readFile(backupPath, 'utf8'));
  expect(backup).toMatchObject({ app: 'open-copilot', version: 1, exportedAt: expect.any(Number) });
  expect(backup.notes).toEqual(before);

  // The backup is recorded and the usual banner is back.
  await expect(page.getByText('已備份 1 篇筆記')).toBeVisible();
  await expect(page.getByRole('note')).toContainText('手動輸入累了？');
  expect(await page.evaluate(() => localStorage.getItem('oc.lastBackupAt'))).toMatch(/^\d+$/);

  // 清空資料: a new browser context starts with empty IndexedDB and localStorage.
  const fresh = await browser.newContext();
  try {
    const restored = await fresh.newPage();
    await restored.goto(new URL('/', page.url()).href);
    await expect(restored.getByRole('textbox', { name: '標題' })).toBeVisible();
    const list = restored.getByRole('list', { name: '筆記清單' });
    await expect(list.getByRole('listitem')).toHaveCount(1);
    expect(await savedNotes(restored)).toHaveLength(1);

    await importFrom(restored, backupPath);

    await expect(restored.getByText('已匯入 1 篇，略過 0 篇（本機版本較新）')).toBeVisible();
    await expect(list.getByRole('listitem')).toHaveCount(2);
    await expect
      .poll(async () => (await savedNotes(restored)).find((n) => n.id === before[0]!.id))
      .toEqual(before[0]);

    // The same file again: the local copy is as new, so nothing is imported.
    await importFrom(restored, backupPath);
    await expect(restored.getByText('已匯入 0 篇，略過 1 篇（本機版本較新）')).toBeVisible();
    await expect(list.getByRole('listitem')).toHaveCount(2);

    await list.getByRole('button', { name: /^週會紀錄/ }).click();
    await expect(restored.getByRole('textbox', { name: '標題' })).toHaveValue('週會紀錄');
    const body = restored.getByRole('textbox', { name: '筆記內文' });
    await expect(body).toContainText('第一點');
    await expect(body.locator('strong')).toHaveText('重要');
  } finally {
    await fresh.close();
  }
});
```
